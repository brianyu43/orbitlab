# P0 진단 결과: 단일 도형 생성

2026-09-23. 이 문서는 새 모델의 성능 결과가 아니다. 기존 저장 모델과 작은 학습 자료를 이용해 우선 원인을 좁혔다.

새 개발 자료 1,792장의 기본 그림 회전 궤도는 과거 기록 11,776개와 겹치지 않았다. 현재 자료의 모양·색 라벨 순서, 픽셀 범위, train/validation/test/제외 조합 분리가 맞았다. 기존 저장 생성 표현 96개를 CPU에서 다시 그려 평가했을 때 모양·색 및 엄격 판정 96개가 저장 판정과 일치했다. 회전 관련 encoder·decoder·flow 오차는 모두 1e-5 이하였다. [자료·회전 검사](p0_data_c4_v1.json) · [저장 결과 재생](p0_saved_replay_v1.json)

도형 생성 규칙을 알고 직접 그린 정상 그림 768장은 모두 모양·색과 엄격한 평가를 통과했다. 이는 평가기가 정상 그림을 대체로 거부하고 있어서 15.6%가 낮다는 설명에는 맞지 않는다. 이 검사는 알려진 규칙을 쓰는 비학습 참조다. [정상 그림 평가](p0_clean_renderer_v1.json)

기존 C4 생성 모델 한 개의 같은 noise 768장에서 Euler 64회 엄격 성공은 학습 조합 18.28%, 제외 조합 11.72%였다. 같은 velocity 호출 64회의 Heun 32단계는 18.44%/10.16%, Euler 256회는 18.28%/10.16%였다. 수치 적분을 더 정교하게 하거나 단계를 늘리는 것만으로 현재 문제가 해결된 증거는 없다. 단일 개발 checkpoint의 작은 표본이며 독립 확인 15.6%를 대신하지 않는다. [적분기 비교](p0_solver_v1.json)

학습 그림 64장 중 20개 학습 조합을 모두 넣고 AE를 6,000회 학습하자, 그 64장의 네 회전 복원은 98.44%가 엄격 기준을 통과했다. 그 중 각 조합의 한 그림을 압축한 표현 20개로 flow를 4,000회 학습하면, 학습 조건당 새 noise 8개에서 모양 88.13%, 엄격 통과 65.00%였다. AE는 이 작은 자료를 거의 외웠지만 flow의 새로운 생성은 같은 조건에서도 형태·윤곽이 흔들렸다. 이는 train 조건의 진단이고 새로운 그림 일반화 점수가 아니다. [작은 AE 학습](../runs/tiny_v1/ae/run.json) · [작은 flow 학습](../runs/tiny_v1/flow/run.json) · [생성 예시](../runs/tiny_v1/flow/train_condition_samples.png)

기존 저장 생성 표현은 실제 학습 그림을 압축한 표현과 분포·복원 순환 오차가 달랐다. 중간 표현의 분포 차이를 시사하는 기술 통계이며 생성 코드가 표현 공간 밖에 있다는 증명은 아니다. 특히 제외 조합에는 동일 조건의 학습 코드가 없어 같은 조건 최근접 거리를 정의할 수 없다. [표현 진단](p0_latent_v1.json)

다양성 판독을 실제 그림 2,048개 회전본으로 검증했다. 지그재그는 180도 회전한 모습이 같으므로 구별 가능한 방향 두 구간을 사용한다. 이 측정 정정과 중심·크기 구간은 모델 결과 확인 전에 고정했다. [판독 기준](p0_diversity_reader_lock_v1.json) · [수정 사유](../AMENDMENT_01_KO.md)

첫 우선순위는 decoder의 윤곽 효과와 flow의 조건 선택 효과를 나누는 P1 비교다. 새 concat 구현은 기존 flow의 초기 가중치와 출력이 완전히 같고, FiLM은 파라미터가 8.56% 더 많으며 회전 수치 검사와 학습 신호 검사를 통과했다. 구조가 다른 두 모델의 성능 차이를 곧바로 조건 전달만의 순수 효과로 해석하지 않는다. [모델 사전 검사](p1_model_preflight_v1.json)
