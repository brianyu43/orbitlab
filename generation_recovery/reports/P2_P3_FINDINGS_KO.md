# P2·P3 개발 결과와 확인 후보

P2 직접 픽셀 U-Net은 797,443개 파라미터로 4,000단계를 약 436초에 학습했다. 별도 생성 24조건 × 8개(192개)에서 엄격 통과는 본 조합 3.75%, 제외 조합 3.13%였다. 모양 일치도 30.63%/28.13%였다. 작은 진단 표본이므로 최종 성능 추정은 아니지만, 동일한 예산의 잠재 공간 모델보다 크게 낮아 전체 개발 평가와 계산량이 네 배인 C4 픽셀 버전은 진행하지 않았다. [학습 기록](../runs/p2_d770101_s0/plain/run.json), [진단 결과](../runs/p2_d770101_s0/plain/validation_8_per_pair.json)

P3에서는 데이터 수·AE·디코더·모델 구조를 유지하고 flow 학습량만 4천→1만6천 단계로 늘렸다. P1의 optimizer와 표본/noise/time RNG 상태를 그대로 이어 받았으며 동일한 24조건 × 80개 개발 생성 noise로 평가했다. [분기 결정](../P3_DECISION_KO.md), [재계산 검증](../evaluation/p3_steps16k_v1/verification.json)

| 설정 / logit mean | 본 조합 엄격 통과 | 제외 조합 엄격 통과 | 크기 TV | 전체 다양성 |
| --- | ---: | ---: | ---: | --- |
| F0 4천 단계 | 23.31% | 14.38% | 0.221 | 실패 |
| F0 1만6천 단계 | 39.00% | 29.06% | 0.196 | 통과 |
| F3 4천 단계, CFG 2.0 | 32.50% | 20.31% | 0.322 | 실패 |
| F3 1만6천 단계, CFG 2.0 | 56.19% | 46.25% | 0.310 | 실패 |

같은 F0를 오래 학습한 효과는 본 조합 +15.69%p, 제외 조합 +14.69%p다. 이 실험에서는 **학습량 부족이 낮은 자동 성공률의 중요한 원인**이라는 근거가 생겼다. F3의 조건 일치와 엄격 통과는 더 높지만, 크기 분포의 총변동거리 0.310이 사전 기준 0.20을 넘으므로 최종 후보에서 제외했다. 모델 선택을 이 개발 결과에서 끝내고, F0 4천 단계와 1만6천 단계만 새 자료에서 대응 비교한다. 확인 설정은 [사전 고정 파일](../confirmation_v1/lock.json)에 저장했다.

이 수치는 데이터 seed 한 개와 초기화 한 개의 개발 결과다. 새 데이터에서 효과가 유지되는지, 엄격 통과물만 보아도 크기·위치·방향 다양성을 유지하는지는 아직 확인 중이다.
