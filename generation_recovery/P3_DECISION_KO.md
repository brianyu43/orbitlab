# P3 분기 결정 (개발 결과 확인 후, 추가 학습 전)

P1의 최상위 잠재 공간 설정(F3, guidance 2.0, logit mean)은 본 조합 32.50%, 제외 조합 20.31%였지만 크기 다양성 기준을 통과하지 못했다. 작은 학습 표본을 외우는 P0 진단은 성공했다. P2의 직접 픽셀 U-Net은 4,000단계를 완료했으나 24조건 × 8개의 진단 표본에서 엄격 통과가 본 조합 3.75%, 제외 조합 3.13%였다. 따라서 픽셀 경로의 전체 평가와 C4 확장은 현재 우선순위가 낮다.

계획의 P3 중 **학습량 축 하나**를 선택한다. P1과 같은 1,024개 학습 원본·AE·decoder·flow 구조를 고정하고, F0와 F3의 flow를 각 4,000에서 16,000단계로 이어 학습한다. 대응 F0를 같이 연장해야 F3의 변화와 단순 학습량 효과를 구분할 수 있다. 두 모델은 P1의 optimizer·표본/noise/time RNG를 그대로 이어 받는다. 평가는 기존 개발 기준과 생성 noise를 재사용한다. F3 guidance는 개발 선별값 2.0으로 고정한다. 다른 단계 수나 guidance를 탐색하지 않는다.

추가 학습 전에 지정한 질문은 다음과 같다: F0/F3 양쪽의 엄격 통과와 크기 다양성이 함께 좋아지는가? F3만 좋아지는가? 둘 다 거의 변하지 않는가? 어느 경우든 이 한 데이터 seed의 결과는 확인 평가가 아니다. 크기 guard가 여전히 실패하면 P4의 성공 확인을 시작하지 않는다.
