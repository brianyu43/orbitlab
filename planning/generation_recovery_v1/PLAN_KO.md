# OrbitLab 단일 도형 생성 개선 계획

작성: 2026-09-23 · 상태: 조사 및 설계 완료, 구현·학습 미실행

우선 추천하는 경로는 **윤곽 복원 개선(logit mean)과 조건 전달 개선(FiLM·CFG)을 각각 검증하고, 작은 직접 이미지 생성기와 비교하는 것**이다. 현재 수치로 가장 분명한 문제는 원하는 모양을 만드는 능력과 선명한 윤곽을 만드는 능력이다. 모델 크기나 학습량 부족은 아직 원인으로 확정하지 않았다.

이 계획은 단일 도형의 엄격 자동 성공률 15.6% 문제를 다룬다. 여러 물체의 인식·편집 실패와 장기 운동 예측 발산은 별도 문제이며, 이 계획의 성공으로 해결됐다고 판단하지 않는다. 모양·색의 범주 입력을 사용하고 자연어 이해는 평가하지 않는다.

## 2. 조사한 해결 방법과 적용 순서

| 우선순위 | 방법 | OrbitLab에서의 구체적인 적용 | 근거의 한계 |
| --- | --- | --- | --- |
| 1 | logit mean decoder | 회전별 출력을 최종 픽셀값으로 바꾸기 전에 평균한다. 같은 encoder·생성 latent로 pixel mean과 비교한다. | 로컬 개발 결과는 있으나 새 데이터 확인이 필요하다. |
| 1 | FiLM 조건 전달 | 모양·색 조건이 각 은닉층의 특징을 확대·축소하고 이동하게 한다. 현재 2개 은닉층에 적용한다. | 원 논문은 시각 추론 연구다. 이 생성 문제의 향상은 가설이다. |
| 1 | classifier-free guidance, CFG | 일부 학습에서 조건을 비워 두고, 생성 시 조건 있는 예측을 더 강조한다. | 모양을 더 따르는 대신 다양성이 줄 수 있다. 무조건 분기를 학습하지 않은 기존 모델에 단순히 붙일 수 없다. |
| 2 | 픽셀 공간의 작은 U-Net flow | 압축·복원을 거치지 않고 64×64 그림을 직접 생성한다. | 표현의 병목을 비교하기 위한 기준선이다. 더 많은 계산이 필요할 수 있다. |
| 조건부 | Spatial Broadcast Decoder | 압축값을 화면 전체에 펼치고 x·y 좌표와 함께 작은 CNN으로 그린다. | 좌표 도입만으로 C4 관계가 보장되지 않는다. branch 회전 구조와 수치 검사가 필요하다. |
| 조건부 | 표현 규제 또는 공간 구조를 가진 latent | 생성된 표현과 실제 그림을 압축한 표현의 차이가 큰 경우에만 시험한다. | latent를 무조건 정규분포로 만들 필요는 없다. 정규화 자체가 해결책이라는 근거도 아직 없다. |

FiLM의 특징별 affine 변환을 현재 조건 전달에 적용하자는 제안이다. [FiLM, AAAI 2018](https://arxiv.org/abs/1709.07871v2)

CFG는 조건·무조건 예측을 함께 학습해 품질과 다양성을 조절한다. Flow Matching의 공식 이미지 구현에도 조건 제거 학습과 CFG가 있다. [CFG 원 논문](https://arxiv.org/abs/2207.12598v1), [공식 학습 구현](https://github.com/facebookresearch/flow_matching/blob/main/examples/image/training/train_loop.py), [공식 생성 구현](https://github.com/facebookresearch/flow_matching/blob/main/examples/image/training/eval_loop.py)

직접 이미지 생성 기준선은 공식 Flow Matching 이미지 예제를 참고해 이 과제 크기로 새로 설계한다. 공식 대규모 실험의 재현이라고 부르지 않는다. [가이드](https://arxiv.org/abs/2412.06264v1), [공식 이미지 예제](https://github.com/facebookresearch/flow_matching/tree/main/examples/image)

좌표를 이용한 decoder는 원 논문의 VAE 실험에서 복원·표현 개선을 보였다. latent diffusion은 압축 표현과 생성 품질의 관계를 설계할 때 참고할 수 있다. 두 연구 모두 현재 OrbitLab의 병목을 직접 입증하지 않는다. [Spatial Broadcast Decoder](https://arxiv.org/abs/1901.07017v2), [Latent Diffusion Models](https://arxiv.org/abs/2112.10752v2)

## 3. 단계별 실행 설계

### P0. 평가·구현·수치 오차를 먼저 분리

1. 기존 checkpoint·noise·평가기를 읽어 저장 점수를 재생한다. 새 코드는 별도 디렉터리에 작성하고 기존 결과·ZIP·상태 파일을 수정하지 않는다.
2. 모양·색 라벨 순서, 이미지 범위, latent의 train-only 평균·표준편차, 회전 작용과 조건의 일관성을 확인한다. 새 수치 검사의 FP32 C4 최대 절대 오차 목표는 1e-5이며 초과하면 정밀도·구현 원인을 기록한다.
3. 학습용 그림 64개를 외우는 AE와, 조건별 고정 도형을 만드는 작은 flow를 각각 하나만 학습하는 진단을 설계한다. 각각 최대 6,000/4,000 steps. 같은 학습 표본에서 엄격 통과 95%를 진단 목표로 사용한다. 이는 일반화 점수가 아니다. stochastic flow의 MSE가 정확히 0이어야 한다는 조건은 두지 않는다.
4. 저장 모델에서 같은 noise로 Euler 64회와 Heun 32단계(velocity 평가 64회)를 비교한다. Euler 256회는 수치 민감도 확인용이다. 계산이 더 드는 결과를 무료 개선으로 세지 않는다. 검증용 24조합 × 32개만 먼저 생성한다.
5. 실제 그림의 압축값과 생성 latent를 비교한다. 조건별 probe, train 기준 정규화 거리, `E(D(z))`와 `z`의 차이를 기록한다. 거리 하나만으로 표현 공간 밖이라고 단정하지 않는다.
6. 정답 도형 규칙으로 직접 그린 이미지도 같은 평가기에 넣는다. 평가기의 정상 그림 통과율과 renderer의 상한을 확인하는 용도다. 정답 규칙을 아는 비학습 renderer는 학습 모델의 성취와 분리한다.

구현 오류·평가 불일치가 발견되면 먼저 고치고 다시 비교한다. 적분기만으로 validation 엄격 통과가 10%p 이상 좋아지면 해당 수정과 이전 방식을 먼저 비교하고 구조 실험의 범위를 줄인다. 정상 그림도 잘 통과하지 못하면 평가기 버전을 따로 검토하며, 기존 임계값을 몰래 낮춰 성공률을 올리지 않는다.

산출물: `diagnostic_report.json`, 고정 사례 contact sheet, 분리된 시간·메모리 측정. 이 계획 작성 시점에는 생성하지 않았다.

### P1. 윤곽과 조건 전달의 효과를 분리

개발용 새 데이터 한 묶음의 기본 그림 1,024개, 같은 20개 학습 조합과 제외 4개 조합을 사용한다. C4 회전본을 별도 독립 장면으로 세지 않는다. 초기화 0에서 먼저 비교하고 개선 방향이 확인될 때만 1·2로 반복한다.

먼저 C4 AE 하나를 기존 조건 6,000 steps로 학습한다. encoder를 고정한 뒤 **두 decoder**를 각각 6,000 steps 학습한다. 두 decoder의 초기 가중치·표본 순서·파라미터·최적화 설정은 동일하다.

| ID | flow 조건 전달 | 학습 시 조건 제거 확률 | 생성 시 guidance |
| --- | --- | ---: | --- |
| F0 | 기존 입력 concat | 0 | 없음 |
| F1 | 은닉층별 FiLM | 0 | 없음 |
| F2 | 기존 입력 concat | 0.1 | 강도 1, 1.5, 2, 3을 validation에서 비교 |
| F3 | 은닉층별 FiLM | 0.1 | 같은 비교 |

각 flow는 같은 고정 encoder 위에서 4,000 steps, batch 128, lr 0.001로 학습한다. F0/F2와 F1/F3는 구조별 동일 초기 가중치를 쓰고, 학습 장면·noise·시간 표본의 RNG를 dropout RNG와 분리한다. FiLM과 concat은 구조가 달라 모든 가중치가 동일하다고 주장하지 않는다. 은닉층 수·폭은 같게 시작하고 추가 조건층의 파라미터와 실제 학습 시간을 공개한다. FiLM 향상을 조건 전달만의 효과로 주장하려면 비슷한 파라미터 예산의 concat 대조를 최대 3회 추가한다.

각 flow가 만든 **같은 latent를 두 decoder 모두로 그린다.** decoder 비교를 위해 flow를 다시 학습하지 않는다. F0/F1은 조건을 제공하는 일반 생성이다. F2/F3에서는 guidance 1과 더 큰 강도를 비교해 조건 제거 학습의 효과와 생성 시 강조 효과를 나눈다.

guidance 정의는 `v_null + s × (v_cond − v_null)`이며 s=1이 일반 조건부 생성이다. 공식 코드의 `cfg_scale=w`는 `(1+w)v_cond − w v_null`이므로 여기의 s=1+w에 해당한다. 두 표기를 혼동하지 않는다. C4를 유지한 조건·무조건 velocity의 선형 결합을 사용한다.

**최초 비교는 AE 1 + decoder 2 + flow 4 = 학습 7회**다. P0의 외우기 진단 최대 2회는 따로 센다. 초기화 세 개까지 모두 반복하면 P1은 학습 21회다. 처음부터 모든 후속 분기를 돌리지 않는다.

선별 규칙: validation은 24조합 × 80개를 사용한다. 본 조합 엄격 통과가 대응 F0보다 5%p 이상 높고, 제외 조합이 2%p 넘게 나빠지지 않으며, 아래 전체 생성물의 다양성·색 보존 조건을 만족하면 추가 초기화로 반복한다. 이 작은 표본에서 엄격 통과물 수가 부족하면 해당 부분의 다양성은 미확인으로 남기고 최종 확인 단계에서 판정한다. decoder 단독 효과는 같은 flow·noise에서 비교한다. 개선이 없으면 최대 2개 조합만 P2/P3 진단에 남긴다. 최종 확인 전에 decoder 종류·guidance 강도·solver·학습 종료점을 확정한다.

### P2. 압축 과정을 생략한 기준선으로 병목을 가리기

64×64 RGB에서 직접 학습하는 작은 conditional U-Net flow를 만든다. 시작안은 채널 32/64/64, 단계별 residual block 2개, 시간 및 모양·색 조건이다. 공간 attention은 첫 비교에서 생략한다. 최종 세부 구조는 학습 전 설정으로 기록한다.

먼저 C4 회전 자료를 제공하는 일반 U-Net 한 개를 시험한다. 100 step 처리량과 24조합 × 8개 생성·평가 시간을 측정한 다음, 4,000 steps의 예상 비용을 기록한다. 각 모델의 로컬 학습에는 우선 30분 상한을 둔다. 상한에 걸리면 `budget_limited`로 남기며 과제나 구조가 실패했다고 단정하지 않는다. batch는 메모리 측정 후 고정한다.

유망하면 같은 raw U-Net의 출력을 네 회전에 대해 평균하는 C4 버전을 추가한다. 일반·C4 각각 최대 초기화 3개, 총 6회로 제한한다. 두 모델은 같은 학습 시간 비교를 포함하고 실제 완료 steps를 보고한다. 잠재 공간 모델과는 전체 encoder/decoder 학습·생성 비용까지 함께 제시한다. 채널 수나 solver 호출 수만으로 같은 비용이라고 주장하지 않는다.

처음은 CFG를 끄고 압축 경로의 유무를 비교한다. P1에서 검증된 조건 강화가 있어도 바로 모두 섞지 않는다. U-Net의 성공은 압축 경로를 우선 조사할 근거지만, 구조·용량까지 바뀌므로 ‘압축이 유일한 원인’이라는 증거는 아니다.

| 결과 | 다음 결정 |
| --- | --- |
| latent 개선 모델도 충분히 좋아짐 | 비용이 낮은 모델을 우선 최종 확인한다. |
| 직접 픽셀 생성은 좋고 latent 생성은 낮음 | latent와 decoder의 인터페이스 개선을 P3에서 우선한다. |
| 두 방식 모두 낮고 작은 자료조차 못 외움 | 라벨·스케일·손실·수치·최적화부터 재점검한다. |
| 작은 자료는 외우지만 새 그림에서 낮음 | 데이터 다양성·학습량·조합 일반화 문제를 나눠 시험한다. |

### P3. 관측에 따라 한 분기만 추가

| 관측 | 선택할 추가 실험 | 규모 상한 |
| --- | --- | --- |
| 실제 그림을 압축했다가 복원해도 윤곽이 크게 무너짐 | frozen encoder 위 Spatial Broadcast Decoder, C4 branch 회전 유지 | 3회 |
| 복원은 좋고 생성 latent와 실제 인코딩의 차이가 큼 | train 표준화 latent에 작은 등방 잡음 σ=0.01/0.03을 넣는 decoder 강건화부터 비교 | 2후보 × 3초기화 = 6회 |
| decoder 강건화도 효과 없고 픽셀 기준선이 우수함 | 공간 latent 또는 약한 KL 규제 AE 중 하나를 별도 프로토콜로 설계 | 이번 실행 범위 밖; 자동 확장 안 함 |
| 과적합 또는 학습 부족 정황이 뚜렷함 | 선택 모델의 train 1,024→4,096을 같은 steps로 비교, 또는 4k→16k를 같은 데이터로 비교 | 선택한 한 축의 추가 수준 × 3초기화 = 3회 |
| FiLM의 향상을 용량 증가와 분리해야 함 | 파라미터 예산을 맞춘 concat 대조 | 최대 3회, 다른 분기와 합쳐 P3 6회 이내 |

잡음 강건화는 이 프로젝트의 실험 제안이며 LDM 논문의 재현이 아니다. 회전별로 다른 정규화나 좌표 처리로 C4가 깨지지 않게 검사한다. shape supervision을 AE에 추가하는 방식은 추가 라벨 정보를 주는 별도 설정이므로 첫 비교에서는 제외한다.

EMA는 필요한 경우 동일 학습 과정에서 가중치 평균본을 별도 기록해 raw/EMA를 검증할 수 있다. 적용한다면 계수와 warmup을 사전에 고정하고, 첫 FiLM/CFG 원인 비교의 필수 변경에는 넣지 않는다. ‘데이터를 크게 늘리면 해결된다’는 가정으로 모든 후보를 확대하지 않는다.

### P4. 최대 두 후보만 새 자료로 최종 확인

기존 C4 기준 + 개선 후보 최대 2개를, 새 데이터 생성 seed 3개 × 초기화 3개에서 평가한다. **최대 27개 모델 경로**이며 AE·decoder·flow 각각의 학습 횟수와는 단위가 다르다. 같은 encoder를 쓰는 경로는 공유한다. 후보가 하나면 18개 경로다.

새 seed·noise 목록과 최종 설정의 해시를 평가 전에 저장한다. 정확한 seed 값은 중복 검사를 거쳐 실행용 lock 파일에 정하며 현재 draft에는 비워 둔다. 기존 개발/확인 자료와 회전 궤도·완성 이미지 중복을 검사한다. 이미 본 43001/43002/43003의 결과는 새 확인 자료가 될 수 없다.

모델당 24조합 × 128개 = 3,072개 생성(학습 조합 2,560개, 제외 조합 512개)을 사용한다. 같은 차원의 모델끼리 noise를 맞춘다. latent와 픽셀 모델은 차원이 다르므로 같은 noise tensor를 썼다고 주장하지 않으며, 조건·표본 ID·평가 예산만 맞춘다.

모델 선택은 개발 validation에서 끝낸다. 최종 test·새 noise의 결과를 보고 guidance·steps·checkpoint·seed를 다시 고르지 않는다. 데이터 3개별 효과를 먼저 보고 초기화 평균을 낸다. 생성 이미지 수천 장이나 초기화 9개를 독립 데이터 수로 세지 않는다.

제외 조합은 ‘각 모델의 학습에서 제외된 모양·색 조합’이다. 기존 4개 제외 조합 자체는 이미 연구자가 관찰했다. 따라서 새 결과를 전혀 본 적 없는 조합 설계에 대한 검증이라고 부르지 않는다. 그 주장을 하려면 제외 조합 패턴을 바꾼 별도 확인이 필요하다.

## 4. 평가와 의사결정 기준

주 지표는 기존 **엄격 도형 기준 AND 요청한 모양·색 일치**다. [고정 평가 설정](../../followup/reports/evaluator_calibration_v1/locked_threshold.json)의 IoU 0.8, margin 0, 최대 점유율 0.35를 유지한다. 평가기 점수를 직접 최적화하는 보상·loss는 사용하지 않는다.

| 평가 축 | 기록 방법 |
| --- | --- |
| 의미 정확성 | 모양, 색, 동시 일치를 따로 기록. 24조합별 표와 seen/excluded macro 평균. |
| 윤곽 | 엄격 통과율, template 적합도, 끊어진 성분·빈 그림 비율. 복원에서만 입력 그림과 mask IoU·경계 오차 비교. |
| 다양성 | 모든 생성물과 엄격 통과물 각각의 중심·크기·방향 분포. train 이미지와의 최근접 비교·동일 복사율. |
| 비용 | 학습, 생성, decoder, 평가, 저장 시간을 분리. wall time·메모리·실제 raw network 평가량 기록. |
| 대칭 | encoder/decoder/velocity/최종 생성의 C4 관계를 고정 입력으로 검사. |
| 시각 검토 | 고정 seed로 고른 작은 blind contact sheet. AI 판정과 사람 판정을 별도 기록. 사람 240개 추가 판정을 요구하지 않는다. |

임의로 생성한 그림에는 위치·크기가 동일한 유일한 정답 이미지가 없다. 별개의 정답 그림에 대한 픽셀 MSE를 생성 정확도로 쓰지 않는다. 템플릿으로 추정한 위치·크기는 불량 생성물에서 틀릴 수 있으므로 판독 가능 비율도 함께 남긴다. 높은 점수의 이미지만 골라 주 지표의 분모를 바꾸지 않는다.

다양성 guard의 제안값은 다음과 같다. 새 정상 그림 reference와 생성 표본을 조합별 같은 수로 맞추고, 고정된 중심 3×3·반지름 3·방향 4개 구간의 **각 주변 분포**를 비교한다. 정상 reference가 채운 구간의 최소 90%를 생성물도 채워야 하며, 총변동거리(TV)는 각 속성에서 0.20 이하여야 한다. 전체 생성물과 엄격 통과물 각각에 적용하고, 조합별 통과물 32개 미만이면 통과물 다양성은 검증 불충분으로 기록한다. 최종 판정에서는 데이터 seed별로 초기화 세 개의 출력을 모아 분포를 검사하되, 이는 독립 데이터 수를 늘리는 처리가 아니다. development에서는 통과물 수 부족만으로 반복 실험을 차단하지 않고, P4의 개선 완료 판단에는 통과물 다양성 확인까지 요구한다. 빈 칸을 인위적으로 메우는 후처리는 하지 않는다. 최종 bin 경계·판독법은 P0에서 정상 reference로 검증한 뒤 학습 전 lock 파일에 고정한다.

CFG는 같은 solver 단계에서도 조건/무조건 평가가 추가된다. C4 네 방향 평균도 비용을 더한다. 예를 들어 s>1의 C4 CFG는 velocity 한 번에 raw 평가 8개에 해당할 수 있다. 배치화에 따른 실제 시간은 별도 측정한다. 공식 구현의 wrapper NFE는 CFG 내부의 두 forward를 하나로 세므로 이 숫자만으로 추론 비용을 맞추지 않는다. 최종 비교에는 각 방식의 선택된 품질 설정과, 기준 모델과 같은 측정 시간 안의 설정을 함께 제시한다.

**첫 개선 목표는 seen 엄격 통과 30% 이상, 제외 조합 20% 이상**이다. 이는 현재 달성값이나 예상 성공률이 아니라 실행 여부를 판단할 제안 목표다. 동시에 새로 학습한 대응 기준보다 seen 평균 +10%p, 제외 조합 +5%p 이상, 각 데이터별 어느 쪽도 2%p 넘게 악화되지 않는 것을 요구한다. 색 일치는 seen/excluded 각각 95% 이상이며 다양성 guard를 통과해야 한다.

이 조건을 통과해도 ‘안정적 제품 수준’이나 ‘사람 검증 완료’라고 부르지 않는다. 개선 방향이 재현됐다는 첫 이정표다. 데이터 3개로 효과의 정밀한 통계적 확정이나 다른 도형·현실 영상에 대한 일반화를 주장하지 않는다.

## 5. 시간과 작업량 관리

| 묶음 | 최대 규모 | 진행 조건 |
| --- | ---: | --- |
| P0 | 읽기·재평가 + 작은 학습 2회 | 평가·구현 진단 |
| P1 첫 비교 | 학습 7회 | P0 오류 해결 후 |
| P1 반복 포함 전체 | 학습 21회 | 유망 후보가 있을 때 나머지 초기화 |
| P2 | 직접 이미지 모델 최대 6회 | 압축 경로 비교가 필요할 때 |
| P3 | 추가 학습 합계 최대 6회 | 표의 관측에 맞는 한 분기 중심 |
| P4 | 최대 27개 전체 모델 경로 | 후보 최대 2개와 프로토콜 확정 후 |

이 수치는 전부 합쳐 즉시 실행할 작업 목록이 아니다. 최초 구현·진단·7회 비교 결과에서 다음 분기를 정한다. 새로운 구조의 시간은 아직 측정하지 않았다. 기존 작은 C4 AE+flow의 학습만 약 87초/경로였던 기록은 전체 파이프라인 시간이나 U-Net 시간의 예측치로 쓰지 않는다.

실행 시 첫 100 training steps와 소규모 생성·평가의 실측으로 단계별 소요 시간을 갱신한다. 30분 로컬 학습 상한과 디스크 여유를 기록하고, 초과 시 결과를 `budget_limited`로 보존해 확대 여부를 별도 계획한다. 원격 GPU·외부 업로드는 이 계획에 포함하지 않는다.

출력은 묶음 tensor/NPZ와 행 단위 metrics를 기본으로 하고, 시각 검토용 일부만 PNG로 저장한다. checkpoint·config·noise·평가 버전의 해시와 재생 명령을 남긴다. 정상/실패/시간 상한 중단을 모두 기록하고 결과를 보면서 실패 seed를 교체하지 않는다.

## 6. 연구로서 남겨야 할 결론

목표는 좋은 그림의 점수 상승과 함께 **어떤 변경이 무엇을 고쳤는지** 설명하는 것이다. decoder가 윤곽만 개선했는지, FiLM·CFG가 요청한 모양을 더 따르게 했는지, 그 대가로 다양성이 줄었는지, 같은 계산 예산에서도 C4의 이득이 남는지를 분리한다.

직접 픽셀 생성기가 더 잘되면 latent 표현의 조건을 연구할 수 있고, 두 방식 모두 특정 제외 조합에서 실패하면 조합 일반화를 연구할 수 있다. 이처럼 실패를 가르는 통제 실험이 기존의 ‘대칭을 넣었더니 조금 좋아졌다’보다 분석할 가치가 크다. 특정 연구실의 관심이나 논문 채택 가능성을 보장하는 주장은 아니다.

이 폴더의 [protocol.json](protocol.json)은 실행 전 설계 명세다. 실행 프로그램이 아니며 `draft_not_run` 상태다. [evidence_snapshot.json](evidence_snapshot.json)은 확인한 로컬 수치·파일 해시·외부 근거, [verification.json](verification.json)은 계획 파일의 정적 검사를 담는다. 새 학습·성능 검증 완료를 뜻하지 않는다.
