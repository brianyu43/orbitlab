# OrbitLab 남은 병목 확인·개선 실험

2026-09-29. 사용자 요청에 따른 새 실행 범위. 이전 결과는 수정하지 않는다.

## 완료의 의미

모든 사전 지정 비교를 실행·검증하고 성공과 실패를 보고한다. 성능 목표를 달성하지 못한 것을 완료로 바꾸지 않는다. 독립 사람 평가와 공식 외부 벤치마크는 실제 수행 여부를 별도로 표시한다. 미래 연구 제안은 이번 실험 결과와 구별한다.

## 실행 순서

1. G0: 기존 9개 확인 모델의 복원 오류를 실제 크기·모양별로 분해하고, 생성 오류는 추정 크기임을 명시하여 비교한다.
2. G1: 같은 C4 AE에서 균등 표본 대조와 모양·색·크기 층화 표본의 decoder/flow를 비교한다. decoder 변경과 flow 변경을 분리한다. 기존 평가기·64-step 생성·다양성 기준을 유지한다.
3. G2: 개발 자료에서 고정한 후보 하나를 새 데이터 3개×초기화 3개로 확인한다. 새 train/val/test/OOD 회전 궤도는 과거 자료와 중복을 제거한다. 학습·평가 원자료와 가중치 해시를 보존한다.
4. P: RGB 기반 물체 인식의 기존 모델을 대조로, 공간 정보를 보존하는 방법을 비교한다. 정답 상태 입력·알려진 renderer 활용·학습한 지각을 분리한다. 모양/방향/좌표, 전체 편집 성공, 비대상 보존을 평가한다. 2/3/4물체·가림·미관측 조합을 유지한다.
5. D: 기존 한 단계 transition과 다단계 학습 및 안정성 제약을 분리 비교한다. 정답 초기 상태와 영상 추정 초기 상태를 구분하고 1/16/61단계 오차, 비유한 실패·유한 발산, 대상/비대상 행동 반응을 모두 기록한다. 물리 참조를 포함한다.
6. E: 공식 SVIB 자료·프로토콜의 현재 접근 가능성과 로컬 자원을 확인한다. 축소 실험을 공식 전체 벤치마크로 표시하지 않는다. 사람 검토는 AI 판정으로 대체하여 주장하지 않는다.
7. V: 새 결과 재계산, 저장 예측 재생, source/data/checkpoint 해시 검증. 기존 manifest 보호 확인.
8. R: 한국어 쉬운 최종 설명, 영문 기술 보고서, 재현 명령과 결과 목록, 미달 목표, 다음 연구의 구체적 실험표를 작성한다.

## 공통 규칙

- CPU 4 threads로 시작하고 pilot 실제 시간에 근거해 실행한다. 외부 유료 계산은 사용하지 않는다.
- 새 개발 결과를 본 뒤 확인 자료를 바탕으로 설정을 바꾸지 않는다. 각 하위 실험의 상세 설정은 실행 전에 JSON으로 저장한다.
- 3개 초기화를 독립 데이터 3개로 세지 않는다. 전체 평균뿐 아니라 seed별·조건별 실패도 공개한다.
- 실행 중간 checkpoint와 상태 기록을 저장하여 재개 가능하게 한다.
- 인간 검증·새로운 과제 일반화·인과 발견·통합 세계 모델은 해당 증거 없이는 주장하지 않는다.
