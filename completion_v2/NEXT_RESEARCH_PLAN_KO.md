# 다음 연구: 어떤 정보를 보존해야 조작과 장기 예측이 함께 가능한가?

이 문서는 **이번 실행 이후의 연구 계획**이다. 아래 실험을 이미 끝냈다는 뜻은 아니다. 이번 완료 범위와 결과는 `RESULTS_KO.md`와 `scope_audit.json`에서 구분한다. 새로운 논문 수준의 기여를 단순히 ‘회전 규칙을 넣었다’ 또는 ‘물체별 표현을 썼다’로 주장하지 않는다.

## 1. 하나의 질문으로 좁히기

그림에서 물체의 상태를 읽을 때 무엇을 잃는지, 상태를 다음 시점으로 옮길 때 어떤 오류가 누적되는지, 마지막으로 그림으로 되돌릴 때 어떤 세부 정보가 사라지는지를 **같은 입력과 같은 평가 기준으로 분리**한다.

우선순위는 (1) 렌더링 세부 정보에 기대는 방향 판별과 의미 있는 방향 이해 구분, (2) 물체 수 증가에 따른 상호작용 오류 및 발산, (3) 실제로 바뀐 영역을 정확히 그리는 생성이다. 회전 일관성은 보조 조건이며 이 세 능력을 자동으로 보장하지 않는다.

연구실에 제시할 핵심 후보는 다음의 검증 가능한 명제다.

> 표현의 대칭성보다 먼저, 관측에서 식별 가능한 정보와 상호작용 구조를 맞추어야 개입 및 장기 예측이 일반화된다. 각 요소의 효과를 동일한 정보 예산과 계산 예산에서 분리할 수 있다.

현재 자료만으로 이 명제를 입증했다고 쓰지 않는다. 아래의 교차 조건에서 반례까지 시험한다.

## MLML의 공개 연구 방향과 연결하는 방법

2026-09-29 확인한 [KAIST Machine Learning and Mind Lab의 연구 소개](https://mlml.kaist.ac.kr/research)는 구조화된 표현, 생성 세계 모델, 체계적 일반화와 인과·조합·시간 구조를 강조한다. [연구실 홈페이지](https://mlml.kaist.ac.kr/)에는 Dreamweaver도 주요 연구로 소개되어 있다. 따라서 ‘물체 표현을 써서 미래를 예측한다’는 설명만으로는 기존 연구와 차별화되기 어렵다.

우리 쪽에서 제안할 만한 차이는 **같은 픽셀 관측에서 무엇이 식별 가능한지, 렌더러의 흔적을 이용한 점수가 얼마나 부풀려지는지, 그 표현 오류가 물체 수 증가와 장기 개입에서 어떻게 전파되는지**를 재현 가능한 교차 실험으로 밝히는 것이다. 이는 공개 연구 주제와의 연결에 대한 제안이며 연구실의 평가나 관심을 확인받은 것은 아니다. 외부 연락이나 제출은 하지 않았다.

## 2. R1 — 방향 판별이 물체 이해인가, 렌더러의 흔적인가?

이번 방향 감사에서 지그재그의 기하학적 180도 대칭과 실제 픽셀 대칭이 다름을 확인했다. 따라서 엄격한 방향 라벨과 눈에 보이는 모양의 정확도를 따로 측정해야 한다.

- **가설:** 현재의 방향 정확도 일부는 경계의 미세한 래스터 차이에 의존한다. 새로운 렌더러 또는 안티앨리어싱 방식에서는 감소한다.
- **자료:** 개발 seed 886101, 확인 seed 886201–886203. 같은 벡터 장면을 기존 PIL 방식, 대칭을 명시적으로 보존한 방식, 다른 샘플링 해상도/커널 방식으로 그린다. 원본 벡터 장면 단위로 분리하고 그 장면의 모든 회전·렌더링 변형을 같은 split에 둔다.
- **비교:** 이진 crop, 강도 crop, RGB crop. 세 모델의 파라미터 수와 학습 장면 수를 맞춘다. 알려진 renderer의 템플릿 매칭도 비학습 참조로 추가하여 단순한 고정 모양 판독을 새로운 표현 학습의 기여로 과장하지 않는다. 방향 손실은 ‘4방향 라벨’과 ‘진짜 대칭군으로 나눈 방향’을 분리한 3×2 요인 실험으로 사전 등록한다.
- **평가:** 엄격한 상태 정확도, 렌더링 동등성, 모양/색/위치 오차, 편집 후 비대상 보존. 안티앨리어싱 변화에 대한 정확도 하락을 기본 결과로 둔다.
- **판정:** 같은 렌더러에서의 향상만 있으면 렌더러 적응으로 보고한다. 보지 않은 두 렌더링 방식 모두에서 편집 성공률 하락이 5%p 이내이고 기준 모델보다 5%p 이상 높을 때에만 견고성 후보로 넘긴다. 수치는 앞으로의 운영 목표이며 현재 달성했다는 뜻이 아니다.
- **중단:** 같은 벡터 모양이 완전히 같은 픽셀을 내는 경우에는 그 라벨을 구분하는 정확도를 요구하지 않는다. 라벨 정의를 먼저 고정하고 정답 동등류를 공개한다.

## 3. R2 — 색상 분리 없이 물체를 찾고 가림을 다루기

현재 좋은 성능은 알려진 색상표와 서로 다른 물체 색상이라는 도움을 받는다. 그 도움을 제거하는 실험이 다음 실질적 난도 상승이다.

- **가설:** 공간 정보를 유지하는 물체 표현은 가림 없는 장면에 유리하지만, 가림에서는 여러 프레임의 추적 또는 모양에 대한 불확실성 표현이 필요하다.
- **자료:** R1과 별도 seed 887101/887201–887203. 같은 색 물체, 연속 RGB 색, 배경 텍스처, 0/25/50/75% 가림을 교차한다. 학습은 2개 물체, 시험은 2/3/4/6개. 평가 장면당 실제 가시 면적과 존재 물체 수를 저장한다.
- **비교:** 현재 palette crop을 상한에 가까운 진단 대조로 보존한다. 학습된 검출+crop, slot 기반 표현, 다중 프레임 slot/추적을 비교한다. 마스크 지도 유무를 실험 축으로 구분한다. 지도 정보를 더 받은 모델을 ‘구조만 바꾼 효과’라고 해석하지 않는다.
- **구현 범위:** 먼저 6-slot 용량, 64px, 동일 4프레임 입력으로 검증한다. 한 프레임 모델도 같은 첫 프레임을 사용하고 추가 관측 이점은 별도 표로 보고한다. 생성기는 먼저 알려진 renderer를 사용하여 인식 오류를 분리하고, 그 뒤 신경 decoder로 교체한다.
- **평가:** 물체 수 정확도, 누락/합침, 가림 정도별 전체 편집 성공, 클릭 대상 선택, 비대상 보존. 숨은 상태의 한 가지 정답을 맞히는 점수뿐 아니라 가능한 상태 집합의 포함률을 기록한다.
- **진행 기준:** 50% 가림에서 현재 단일 프레임 기준보다 15%p 이상 편집 성공 향상, 비대상 보존 감소 2%p 이내, 세 데이터 seed 모두 같은 방향. 6개 물체에서 누락률 5% 이하를 다음 단계 목표로 둔다. 기준 미달이면 확대하지 않고 누락과 상태 추정을 분리 진단한다.
- **선행 연구:** [Dreamweaver](https://arxiv.org/abs/2501.14174v5)의 물체/속성 표현과 여러 미래 프레임 예측을 비교 대상으로 검토한다. 이번에는 초록 수준 연결만 확인했으므로 본문·코드·라이선스·입력 예산을 먼저 대조해야 한다.

## 4. R3 — 물체 수가 늘어도 안정적인 상호작용 모델

여러 단계 손실만으로 물체 수 일반화가 해결되는지는 이번 결과에서 별도 검증했다. 좌표와 속도 제한은 발산을 막을 수 있지만 올바른 충돌을 배우게 하지는 않는다.

- **가설:** 물체 수에 따라 합산 크기가 변하는 상호작용과 접촉 모델의 부재가 장기 오류의 주된 요인이다. 국소 쌍별 상호작용과 명시적 접촉 처리가 단순 좌표 제한보다 낫다.
- **자료:** 새 seed 888101/888201–888203. 충돌 없는 궤적/벽 충돌/물체 간 충돌을 분리한다. 학습 2개, 시험 2/3/4/6개. 동일 초기 상태와 행동에서 외력만 바꾼 반사실 쌍을 둔다. 관측 4프레임, 예측 1/16/61/128단계.
- **비교:** 이번 one/multi/multi_bounded, 물체 수 정규화 쌍별 메시지 전달, 접촉을 처리하는 물리 모델+학습 잔차. 외력은 알려진 경우와 영상에서 추정한 경우를 각각 비교한다. 학습 모델과 simulator를 그대로 재사용하는 oracle를 혼동하지 않는다.
- **개발 절차:** 2,000-step pilot에서 접촉 없는 운동·벽 충돌·두 물체 충돌을 따로 통과시킨다. 후보 선택은 개발 16/61단계의 오차와 실패율을 함께 사용한다. 시험 수치를 보고 clamp나 충돌 반경을 조정하지 않는다.
- **평가:** 위치·속도 오차, 비유한 실패, 유한 발산, 벽 관통, 물체 겹침, 접촉 시점, 대상/비대상 행동 반응 오차. 반사실 행동에 ‘아무 변화 없음’ 기준도 반드시 유지한다. 실패 궤적을 평균에서 조용히 제외하지 않는다.
- **진행 기준:** 61단계에서 비유한/유한 발산을 합쳐 1% 미만, 1px 초과 벽 관통 궤적 1% 미만 및 물체 겹침 궤적 5% 미만, 네 물체 오차가 이번 bounded 기준 대비 20% 이상 감소, 비대상 반응 오차 악화 5% 이내를 세 데이터 seed에서 모두 만족해야 한다. 성능 좋은 물리 참조와의 격차도 보고한다. 좌표 제한 때문에 실패율이 낮아진 것만으로 물리 학습 성공이라 하지 않는다.
- **선행 연구:** [Aether](https://arxiv.org/abs/2310.20679v2)의 국소 상호작용/전역 장 구분과 비교한다. 기존 프로젝트의 본문·코드 검토를 재사용하되 새로운 실험과 정보 예산을 정확히 맞춘다. 직접 장기 예측 비교 후보는 [Beyond Myopic World Models](https://arxiv.org/abs/2608.07420)이며, 본문과 구현 검증 후에만 포함한다.

## 5. R4 — 작은 모양을 살리면서 생성 다양성 유지하기

- **가설:** 작은 화살표의 복원 병목을 줄이는 표현/decoder가 필요하며, 생성기 표본 비율 조정만으로 해결되지 않을 수 있다.
- **비교:** 현재 decoder와 area/edge 손실, 공간 feature map을 유지하는 decoder, 물체 좌표를 명시적으로 다루는 decoder를 단계적으로 비교한다. 정답 속성에 대한 추가 감독을 쓰면 그 정보 비용을 별도 실험 축으로 표시한다. 먼저 정답 latent 복원, 다음 실제 encoder latent 복원, 마지막 flow 생성으로 평가하여 오류가 생기는 위치를 찾는다.
- **데이터/예산:** seed 889101/889201–889203, 같은 1,024개 학습 장면으로 시작. 개발에서 4개 후보를 비교하고 확인에는 기준+후보 한 개만 3개 데이터×3개 초기화로 실행한다. sample/noise를 짝맞추고 업데이트 수와 실제 계산 시간을 모두 공개한다.
- **평가:** 실제 크기별 복원 성공, 생성 strict 성공, 색/모양/중심/크기/방향 분포, strict를 통과한 표본의 다양성. 생성물 크기는 추정치임을 유지한다.
- **진행 기준:** 작은 화살표 복원 80% 이상, 생성 strict 성공 기준 대비 10%p 향상, 기존 다양성 gate 모두 유지. 어느 하나라도 실패하면 ‘생성 문제 해결’로 승격하지 않는다. evaluator의 threshold는 고정한다.

## 6. R5 — 외부 과제와 통합 모델의 최종 검증

[SVIB 공식 과제](https://systematic-visual-imagination.github.io/)에서 이번에는 Hard dSprites Single Atomic 한 과제만 전체 split을 사용했다. 다음은 동일 과제의 학습량 증가 실험과 다른 과제/시각 복잡도 일반화를 분리한다.

1. 같은 과제에서 학습 곡선을 검토하고 개발 규칙에 따라 5/10/20 epoch를 비교한다. 학습 split에서 미리 떼어 둔 validation으로 선택하고 시험 기준으로 epoch를 선택하지 않는다. 이번에 이미 본 공식 test라는 사실을 기록하며, 새 과제/새 공식 split을 추가 검증으로 사용한다. 입력 복사 기준, plain, C4, 물체 기반 모델을 같은 데이터와 updates에 맞춘다.
2. 같은 Hard dSprites의 Multiple Atomic/Non-Atomic 과제로 확장한다. 그 뒤 CLEVR 한 과제, 마지막 CLEVRTex 한 과제로 순차 이동한다. 각 과제의 공식 split과 라이선스를 새로 확인한다.
3. 이미지 전체 MSE뿐 아니라 바뀐 영역 오차·보존 영역 오차·물체 속성 판독을 분리한다. LPIPS를 추가하려면 공식 구현과 가중치 버전을 고정하고 원래 지표를 대체하지 않는다.
4. 먼저 동일한 움직이는 원형 물체 자료로 R2 인식기·R3 전이·신경 decoder를 각각 재학습해 입력/출력을 맞춘 다음 연결한다. 다각형 충돌은 simulator 검증을 거친 별도 확장으로 둔다. 서로 다른 현재 모델을 바로 연결하면 통합 모델이 된다고 가정하지 않는다. 정답 상태·정답 외력·알려진 renderer를 각각 바꾸는 교체 실험으로 실패 원인을 분리한다.
5. 발전된 결과가 나온 뒤 독립 사람이 출처를 가린 평가를 수행한다. 기존 9개 사람 응답과 231개 AI 응답은 그대로 보존하며, 새 독립 사람 검증으로 세지 않는다. 참가자가 없는 상태에서는 이 단계를 수행 완료로 표시하지 않는다.

외부 과제의 통과 기준은 각 데이터 seed/초기화의 결과, 입력 복사 대비 개선, 바뀌지 않아야 할 영역의 손상, 계산 비용을 함께 보고하는 것이다. 모든 과제에서 성공해야만 연구 가치가 있는 것은 아니지만, 실패를 빼고 평균을 만드는 보고는 하지 않는다.

## 7. 실행 순서·자원·종료 조건

**권장 순서:** R1 → R3의 정답 상태 실험 → R2 → R4 → R5의 통합/외부 검증. R1에서 라벨 의미를 먼저 정리해야 인식 향상을 잘못 해석하지 않는다. R3에서는 인식 오류를 제거한 상태로 물체 수 실패를 먼저 해결한다.

각 단계는 개발 데이터 1개에서 작은 pilot → 코드/정보 예산/기준 잠금 → 새 데이터 3개×초기화 3개 확인 → 재생/해시 검증의 순서다. 세 초기화를 독립 데이터 세 개로 세지 않는다. 데이터 seed 평균과 범위를 기본으로 보고하고, 세 데이터만으로 정밀한 모집단 신뢰구간을 주장하지 않는다.

계산량은 이번 로그의 실제 step 시간에 `업데이트 수×실행 수`를 곱해 잡는다. 새 아키텍처는 100-step 시간·메모리 pilot을 먼저 측정하여 추정 오차를 기록한다. 단계별 초기 상한은 로컬 계산 12시간/저장공간 30GB로 제안한다. 확인 실험 도중 상한에 걸리면 중단 지점과 미완료 seed를 그대로 공개하고, 업데이트 수를 줄인 결과를 원래 계획 완료로 표시하지 않는다. 유료 GPU나 외부 업로드는 이 문서에서 실행하지 않았다.

개발 단계에서 개선이 없으면 3×3 반복을 무조건 늘리기보다 가설을 기각하고 실패 분석을 끝낸다. 반대로 확인 단계에서는 불리한 seed를 삭제하거나 추가 seed로 평균을 바꾸지 않는다. 충분한 근거가 없으면 논문 결론은 ‘한계의 실증과 원인 분리’에 둔다.

**최종 연구 묶음:** 사전 등록, 입력 정보 표, 좌표 손실을 같은 픽셀 단위로 맞춘 비교표, 모든 seed의 결과, 실패 사례, 코드와 체크포인트, 재현 명령, 데이터 출처/해시, 사용 자원, 독립 평가 여부. KAIST MLML Lab을 포함한 연구자가 검토할 수 있는 형태를 목표로 하며, 특정 연구실의 관심이나 채택을 보장하지 않는다.
