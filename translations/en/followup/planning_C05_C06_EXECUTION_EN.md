# C05/C06: A future without giving the correct answer and changing behavior

2026-09-23. This is the execution plan written after completing C04. The evaluation settings below are fixed before viewing the long-term prediction results. They do not change the existing learning and results.

1. **Fix initial information.** Use the C04 estimated state and environment obtained from four images (t=0..3) only once. Compare the correct state + correct environment, RGB direct CNN, video measurement + learning correction, and video measurement + physical equations inputs. Only the first method is the explicit ground truth comparison group. Speed change actions specified by color are only passed to the first prediction.
2. **Maintain the comparison model.** The existing variable_force uses seven learning models (flat/object/interaction/augmented/wrong_exact/joint_exact/relaxed), three initializations, and references to constant speed, external force, and wall reflection without learning. It applies the same weights to all environments and does not select the predictor based on the actual environment name. It does not claim that capacity, time, and prior knowledge are all the same comparison.
3. **Maximum 61-step autonomous prediction.** From t=3 to t=64, the correct state, environment, count, and response are not supplied again. Since the learning material ended at t=19, the time range of the learning material exceeds the 16th step. It records position and speed errors at steps 1/4/8/16/32/61, object omissions and incorrect spatial response, wall penetration and object overlap. It arbitrarily limits the output position and speed or adds physical corrections. If the values are not limited, it records the initial point and keeps the subsequent ones as failures. It presents both the error for a limited case and the overall failure rate.
4. **Specify the limits of collision point indicators.** The model does not generate collision output. It calculates contact candidates by considering the approach from the center between frames, speed changes deviating from free motion, and proximity to walls. The speed residual is fixed at 0.1 pixels per frame and the distance margin is fixed at 1.5 pixels in advance. The same decision is applied even to the original correct state to first disclose the error of the indicator itself. It does not call it the same value as the actual simulator's collision count. It records the difference in the first contact point time, missed/false contact, and TP/FP/FN per frame.
5. **Same past/opposite behavior.** In the 512 response trajectories already generated and verified, the initial estimates and environment are fixed, and only the action symbols are changed. The difference between the two predictions is compared to the difference between the two correct futures. The target and non-target objects are separated. Since the movement of another object through a collision is the correct answer, the score does not require preserving the non-target object unconditionally. The error in the contrast that does not react at all to the action is also recorded.
6. **Independent playback and reporting.** The initial stage is tested against C04's storage predictions (five overlapping predictors). All trajectories are played back from the initial input of storage and major metrics are recalculated in a separate code. Fixed weights, data, and source hashes are verified, and model/condition-specific initializations and scene-level uncertainty are separated. The number of prediction frames is not counted as the number of independent samples.

The original withheld trajectory consists of 1,280 groups of 13, and the opposing behavior comprises 512 of those. The data generation seed is a single one, and research on independent data repetition, observation length, and condition missingness remains in C07. External SVIB, prior research, human judgment, and final replication bundles are also retained as part of the overall goal.
