## Part that I checked directly in implementation

- **Slot Attention:** The softmax of attention is applied to the slot axis, and the weighted average normalized back to the input axis is fed into the GRU. A learnable common Gaussian initialization and shared update are used. This was reflected in the consistency check of the order of the small PyTorch implementation. [Original](https://arxiv.org/html/2006.15055v2), [Official code](https://github.com/google-research/google-research/tree/master/slot_attention)
- **ISA:** There is a branch that separately handles the slot position, scale, and rotation matrices and also passes the relative coordinates to the decoder. The rotation axis estimation in the paper can be ambiguous in symmetric shapes and restricts the rotation range. It is not treated as a guarantee such as the precise global C4 action in OrbitLab. [Main text·appendix](https://proceedings.mlr.press/v202/biza23a/biza23a.pdf), [official code](https://github.com/google-research/google-research/tree/master/invariant_slot_attention)
- **SysBinder:** Uses `BlockGRU`, `BlockLinear`, `BlockPrototypeMemory`, and the image decoder uses block coupling and token transformer. The current small independent object state MLP is not a replication model of that method. [Paper](https://arxiv.org/html/2211.01177v3), [Official Code](https://github.com/singhgautam/sysbinder)
- **Dreamweaver:** In the code, we used time-based binder output and the final state to predict future tokens, select future time points, and check the step indicator. In the paper App. C.5, we find the block to edit by using probe and feature importance analysis with the correct factor and mask matching. We do not describe the entire manipulation process, including this one, as a process with no correct information at all. [Main Text·Appendix](https://arxiv.org/html/2501.14174v5), [Official Code](https://github.com/ahn-ml/dreamweaver-release)
- **SEN:** Implementation uses a contrastive loss that combines latent transition error and a hinge for the vocal state. `TransitionGNN_C4` uses an edge/node function with a rotational structure. Currently, it cannot directly compare the pixel generation loss and metrics from OrbitLab. [Paper](https://proceedings.mlr.press/v162/park22a/park22a.pdf), [Official code](https://github.com/jypark0/sen)

## The location of questions to be verified in the future

The central candidate for subsequent research is **combining directional environmental cues, the extent to which environmental information can be observed, and the control of error in long-term future predictions by combining unobserved combinations** in a single control experiment. This combination has not yet been confirmed to be absent in existing research. The experiment should differentiate between changing only the state and changing both the state, behavior, and environment simultaneously, and comparisons should be made between models that provide conditions, inferring, and are non-public inputs.

The current state of the oracle experiment confirmed the expected advantages of object-level sharing in independent interventions. The original C4 generation experiment separated the effects of flow constraints and decoder. Neither of them validated the environmental condition hypothesis. After completing symmetric experiments conditioned on the conditions, external SVIB model evaluation, and a review of the latest methods that are closer to this, the claim range is determined.
