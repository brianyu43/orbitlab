# OrbitLab follow-up research execution

Start: 2026-09-23. The existing 15th-round data will be preserved as the reference data, and subsequent code, settings, and results will be added to this directory.

The purpose is to identify the cause of the current generation difference and to systematically verify future predictions, including the combination and intervention of objects, as well as environmental conditions. Even if the results differ from expectations, we preserve the comparison and use it as a basis for the next experiment. It does not mean replacing it with a confirmation of accurate symmetry implementation or as evidence for understanding and discovery of causality.

The top questions and literature are in [Research Proposal](../planning/MLML_RESEARCH_ROADMAP_EN.md), the detailed order is in [Worksheet](PLAN_EN.md), and the current execution evidence is managed in `reports/` and `runs/`. The hash check for the original data is performed in the start and final review stages.

Human judgment data are prepared using a review tool that obscures the source and response files. If no actual human judgment is submitted, it is not marked as human verification complete. In this case, the results of the automatic evaluation are retained as a provisional interpretation and subsequent independent work can be carried out.
