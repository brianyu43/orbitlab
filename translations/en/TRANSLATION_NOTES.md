# OrbitLab English translation

This tree mirrors the project's Korean text files in English. The Korean originals, archived snapshots, release bundles, experimental data, and hash-locked protocol files remain unchanged. A source-to-English file map and SHA-256 checks are in [MANIFEST.json](MANIFEST.json).

The archive-wide pass is machine-assisted and has structural checks, but its technical prose has not all been line-edited by a human. It covers readable Markdown and text, human-facing strings in Python and JSON, HTML text, and CSV labels. Paths, filenames, code identifiers, hashes, and numerical data remain in their original form. The Python and JSON copies are translations for reading and review; run experiments from the original project files. Technical claims and numerical results remain governed by the original reports and machine-readable evaluation files.

The current generation-recovery reports also have separately reviewed English copies beside their Korean originals under `generation_recovery/`.

Coverage: 189 translated project text files, assembled from 2,882 unique translated segments. The final check found no broken local Markdown links, Python syntax errors, or invalid JSON in the English mirror. Fifteen Korean characters remain only in three references to the original file name `OrbitLab_Mac_실험계획서.docx`; keeping that exact name preserves the file identity. Six hash/integrity JSON files contain that name only as a path or key and are intentionally left as original records. Installed Python packages in `.venv/` are outside the project translation.
