# 후속 연구 실행 범위

권위 있는 원계획: `../completion_v2/NEXT_RESEARCH_PLAN_KO.md`. 실행 순서와 실패 시 중단 기준을 유지한다. 단계의 실험 종료와 능력 목표 달성은 구분한다.

| 단계 | 필요한 작업 | 종료를 입증할 자료 |
|---|---|---|
| R1 | 동일 벡터 장면의 3개 렌더러, 이진/강도/RGB × 전체/대칭 동등류 방향 손실, 템플릿 참조, 렌더러별 편집·보존 평가 | 사전 등록, 대칭 검사, 개발 결과, 잠긴 선택 규칙, 필요 시 새 3개 데이터×3개 초기화 확인, 재생 검증 |
| R3 | 2개 학습→2/3/4/6개, 충돌 유형별 진단, 1/16/61/128단계, 정규화 상호작용·물리+잔차, 외력 관측 조건, 반사실 | 2000-step 개발, 모든 실패 포함 지표, 접촉·겹침·벽·반응 검사, 조건별 확인·재생 |
| R2 | 같은 색/연속 색/배경, 0/25/50/75% 가림, 6슬롯·64px·4프레임, 검출/slot/추적, 지도 유무 | 가시면적·누락/합침/편집/선택/보존/불확실성, 정보 예산, 실패 원인 분리 |
| R4 | 4개 개발 후보, 작은 모양 복원→encoder→flow, 동일 noise, 기준+선택 후보 확인 | 크기별 성공, strict 생성, 성공 표본 다양성, 고정 evaluator, 계산량 |
| R5 | SVIB 학습곡선·추가 과제, 원형물체 공통 데이터에서 인식/전이/decoder 재학습·교체 실험 | 공식 출처·라이선스·split, validation 선택, 바뀐/보존 영역, 통합 실패 분석 |
| 독립 사람 평가 | 향상된 결과에 대한 출처를 가린 독립 평가 | 실제 참여자·응답·프로토콜. 참여자가 없으면 미수행으로 남기며 AI를 사람으로 세지 않는다. |
| 최종 묶음 | 모든 seed, 실패, 입력 정보, 비용, 코드·가중치·출처, 재현 명령 | 데이터·실험 재생 검증, 원본 보존 감사, 보고서·그림·패키지 |

각 단계 최초 상한은 로컬 계산 12시간/30GB. 개발에서 개선이 없으면 계획에 따라 확인 반복을 무조건 늘리지 않고 실패 분석으로 닫는다. 이러한 경우 생략한 확인 실험과 능력 미달을 명시한다. 확인 시험을 본 뒤 기준을 바꾸지 않는다. 유료 자원·외부 업로드와 사람 모집은 수행한 것으로 가정하지 않는다.
