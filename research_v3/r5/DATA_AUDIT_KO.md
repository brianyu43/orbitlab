# R5 공식 데이터 감사 — 모델 성능 보고서와 구분

6개 과제, 총432,000장면의 원본 입력·출력·메타데이터·마스크를 준비했다. 원본파일2,592,000개를 저장된 SHA256과 대조했으며, RGB와마스크1,728,000장을 모두 디코딩했다. 각 과제는 공식train64,000/test8,000을 유지하고, train에서57,600학습/6,400validation을 나눴다. 단일 장면의 source 또는target이 정확한90도회전 이미지로 겹치면 같은 연결 성분으로 취급한다. 이는 중복 검사용이며3D세계의 회전 대칭성을 주장하지 않는다.

공식test멤버십은 변경하지 않았다. 이미지 해시 중복이 없다는 검사는 모든 가능한 의미 유사성이나 독립 표본성을 보장하지 않는다. 원래 프로젝트에서 이미 쓴dSprites SingleAtomic의 test를 새로 보지 않은 시험이라고 부르지 않는다. 그 외과제와3D자료는 이번후속확장이다. 개선 시 사용할890201–890203의 추가 분할도 같은 공식자료의 재분할이며 새 독립 데이터 세 개가 아니다. 각 분할에3개 초기화를 적용하는 조건부 확인 범위를 유지했다.

## 발견한 조건과 정정

1. dSprites색 메타데이터와 저장RGB의 채널 순서가 다르다. 원본 이미지를 재색칠하지 않고 기록된순서 그대로 학습한다. RGB와마스크를 따로 안티앨리어싱한 경계에는 미세한 색 차이가 생긴다.
2. MultipleAtomic에서는406장, MultipleNonAtomic에서는163장의target마스크 판독색이 물체라벨과 어긋났다. 원본RGB의 새 색상 순서와 마스크의 초기source색상 겹침순서를 다시 그려 확인했다. RGB는각398/406,162/163장이 비트단위로 일치했고 나머지 최대채널차이는255범위에서3/2였다. 초기순서 마스크는399/406,162/163장이 완전히 일치했다. 모든사례를완전재현했다고 과장하지 않으며 원본마스크를 수정하지 않았다. 주모델은 이 마스크를 입력이나 정답감독으로 받지 않는다.
3. MultipleNonAtomic의 quadrant규칙은 세계를90도돌렸을때 모든72,000장면의 목표속성을 바꾼다. 따라서 고정 C4규칙이 맞지 않는 과제로 분리한다. 나머지 세dSprites과제에서는 같은 의미 규칙 검사에서 변화가 없었다. 코드의크기규칙은 상대물체의색과상대quadrant를 쓰며, 논문의self-quadrant표기를 그대로 적용하면88.03%장면에서 다른목표가 나온다. 실행된데이터와코드의정의를명시하며 논문표기를몰래수정한데이터로대체하지 않는다.
4. 첫CLEVR감사는 마스크를red/green이라고가정해 절반의물체에 내부픽셀이없다고 잘못집계했다. 실제CLEVR는black/red와회색배경이고,CLEVRTex는red/green의내부색이약227로렌더링된다. 원감사·소스·결과를audit_3d_preflight_v1에보존하고v2에서모든장면을재검사했다. 비마스크배열은원감사와완전히동일하며,수정후두3D자료모두고신뢰마스크픽셀이없는물체는0개였다. 이는마스크측정의정정으로학습자료나성능기준은바꾸지않았다.
5. CLEVRTex의공식test에서는속성변화가없는1,424장면중1,402장면에아주작은RGB차이가있었다. 이집단의입력복사MSE는약4.91e-7이다. CLEVR의속성동일2,868장면은RGB도동일했다. 따라서정확한픽셀차이영역과의미있는속성변화를별도로보고한다. 그림자·조명변화도픽셀차이에포함될수있다.

## 출처와 경계

공식프로젝트는https://systematic-visual-imagination.github.io/이고데이터라이선스는공식논문AppendixA.6Question4의CC0명시를확인했다. 코드CC0와포함된Spriteworld의Apache2조건을구분한다. dSprites는기존원본아카이브와저장파일을두번째전체패스로대조했다. CLEVR13,921,263,003바이트,CLEVRTex21,205,404,602바이트의공식Hard아카이브전체를스트리밍해해시하고,사전선택한SingleAtomic의원본파일만보존했다. 이두아카이브는독립적인두번째다운로드나배포자체크섬과대조한것은아니다.

검사결과는자료신뢰성과측정정의에대한증거다. 모델의새능력·독립사람평가·실제사진일반화에대한증거로대신하지않는다. 본학습,전체픽셀재생,독립속성판독기보정,통합원형물체실험은각각별도완료여부를기록한다.
