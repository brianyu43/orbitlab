# 사용자 요청에 따른 실험 중단 기록

**2026-09-30(한국 시간), 사용자의 요청으로 실험을 중단했다.** 완료를 선언하거나 통과 기준을 낮춘 것이 아니다. 추가 실험은 자동으로 재개하지 않는다.

진행 중이던 dSprites **Multiple Atomic의 plain·C4 모델을 각각 5 epoch, 9,000/36,000 업데이트에서 멈췄다.** 각 모델의 가중치, 옵티마이저, RNG 상태, 고정 표본 순서 해시, 6,400개 validation 지표를 보존했다. 두 모델의 epoch 5 가중치와 진행 체크포인트가 비트 단위로 일치하고, 모든 옵티마이저 파라미터의 업데이트 수가 9,000임을 확인했다. [체크포인트 검사](review/stopped_checkpoint_verification.json)

학습 두 개, 실행 대기열, 후속 검증 대기, 확인 실험 대기, 자동 복구 프로세스를 모두 종료했다. 마지막 CLEVRTex 채점기의 정답 그림 검증은 완료 후 종료했다. 학습 중 아직 저장되지 않은 메모리 상태는 재개 기준으로 삼지 않으며, 저장된 9,000회 상태가 재개 지점이다.

## 완료한 범위와 남겨 둔 범위

| 항목 | 중단 시점 |
|---|---|
| R1·R3·R2·R4 개발 실험 | 전체 예정 개발 평가와 재생 검증 완료. 모든 확대 기준 미달로 3×3 확인은 시작하지 않음. |
| R5 동일 원형 물체의 인식·전이·decoder 통합 | 다섯 구성 요소 재학습과 57개 교체·대조 조건 검증 완료. 확대 기준 미달. |
| R5 외부 Single Atomic | plain·C4·object 모두 20 epoch 학습. 5/10/20 epoch validation, 7개 공식 test 픽셀·속성 판독 조건 전체 재생 완료. |
| R5 외부 Multiple Atomic | plain·C4 각각 5 epoch 저장 후 중단. object는 시작하지 않음. 20 epoch 개발 완료로 세지 않음. |
| 남은 외부 과제 | dSprites 두 Non-Atomic 과제 및 CLEVR/CLEVRTex primary 모델 학습 미시작. 공식 데이터 감사는 완료. |
| 별도 속성 채점기 | 여섯 과제 모두 학습 및 정답 validation/test 그림 판독 재생 완료. 채점기의 조합 일반화 실패도 함께 기록. |
| 조건부 확인 | Single Atomic의 개발 기준으로 C4가 선택되어 plain+C4의 18개 확인 학습이 요구되지만 미실행. 나머지 과제의 확인 필요 여부는 미정. |
| 새 독립 사람 평가 | 미수행. 기존 사람·AI 응답으로 대체하지 않음. |

외부 primary 모델은 **18개 중 3개 완료, 2개 부분 학습, 13개 미시작**이다. test 픽셀 및 속성 판독 조건은 각각 **7/42개**가 검증됐다. 이것을 전체 연구 완료나 목표 능력 달성으로 바꾸어 쓰지 않는다.

## 현재 결과의 의미

Single Atomic 공식 test에서 C4는 plain보다 픽셀 MSE가 작았다. 그러나 자동 판독의 물체별 모든 속성 정확도는 32.57% 대 29.96%인 반면, **두 물체를 동시에 맞힌 비율은 C4 10.55%, plain 18.11%**였다. 픽셀 개선·개별 물체 평균·장면 전체 조작 성공은 같은 지표가 아니다. 채점기 자체도 정답 그림의 두 물체를 모두 읽은 비율이 60.78%이므로 이를 독립 사람 성공률로 해석하지 않는다. [외부 결과](r5/external_report/RESULTS_KO.md)

원형 물체 통합에서는 정적 검출이 좋아도 장기 미래 예측과 비대상 행동 반응이 부족했다. R1–R4의 음성 결과와 원형 물체 통합의 실패도 그대로 보존한다. [검토 순서](REVIEW_INDEX_KO.md)

## 보존·공개·재개

- GitHub에는 소스, 잠긴 설정, 보고서, 선택된 그림, 요약 및 검증 영수증을 공개한다. 대용량 원본 자료·가중치·예측 배열은 로컬에 유지하며 삭제하지 않는다.
- 공개 저장소만으로 모든 후속 수치를 재학습할 수 있다고 주장하지 않는다. 필요한 자료와 재현 범위는 [재현 안내](REPRODUCE_KO.md), 공개 범위는 루트 `PUBLICATION.md`에 있다.
- 남은 연구의 전체 검토 ZIP은 만들지 않았다. 미완료 셀과 확인 실험이 있으므로 최종 완료 판정을 강제로 만들지 않는다.
- 향후 재개에는 사용자의 새 지시가 필요하다. 종료한 PID를 재사용하지 않는다. 원래 12시간 자원 시계가 벽시계에 연결되어 있으므로 장시간 중단 뒤 재개할 때에는 원본 시계를 덮어쓰지 말고 중단 시간·새 실행 예산을 명시한 수정 기록을 먼저 남긴다.
- [다음 연구 초안](NEXT_STUDY_DRAFT_KO.md)은 미실행 제안이다. 채점기의 독립 조합 검증, 물리 참조보다 나쁜 학습 잔차의 제약, 관측 길이와 불확실성 분리가 후속 후보다.

실험 중단은 사용자 요청에 따른 운영 결정이다. 자원 상한 도달이나 프로그램 오류를 중단 원인으로 보고하지 않는다. 컨트롤러의 SIGTERM 종료 로그가 있더라도 이 기록과 함께 해석한다.
