# 다음 연구 설계 초안: 측정 오류와 예측 오류부터 분리하기

**현재 R5 외부 실험이 진행 중이므로 조건부 초안이다. 아래 새 실험을 실행하거나 성공했다고 주장하지 않는다.** 현재 잠긴 학습·채점·선택 기준을 유지한 채 R5를 먼저 마무리하고, 그 결과에 따라 이 초안을 갱신한 후 다음 실험을 사전 등록한다.

이번 연구의 가장 구체적인 질문은 “회전 규칙을 넣으면 좋아지는가?”보다 “측정기, 인식, 움직임, 그림 복원 중 어디의 실패가 전체 점수를 결정하는가?”이다. 검토자는 같은 입력에서 실패가 생기는 위치를 재현할 수 있어야 한다. [MLML의 공개 연구 소개](https://mlml.kaist.ac.kr/research)에 있는 구조화된 표현·생성 세계 모델·체계적 일반화와 연결되는 방향이지만, 연구실의 관심이나 채택을 확인받은 것은 아니다.

## 먼저 완료해야 할 현재 범위

- R5 여섯 외부 과제 × 세 모델의 20 epoch 학습, 5/10/20 validation 선택, 고정 20 epoch 대조, 전체 픽셀·속성 판독 재생을 끝낸다.
- 개발 기준을 통과한 과제에 한해 기준+후보의 세 재분할 × 세 초기화를 확인한다. 같은 공식 자료의 재분할을 독립 데이터셋으로 세지 않는다.
- 실패·미완료 조건을 모두 남기고 현재 원자료/체크포인트/코드 해시, 정보·계산 예산, 원본 보존 감사를 포함한 묶음을 만든다. 12시간/30GB 상한으로 남는 조건은 결과를 축소해 완료로 표시하지 않는다.
- 독립 사람 평가는 실제 사람이 참여해야 한다. 기존 9개 사람 응답과 231개 AI 응답을 새 검증으로 재사용하지 않는다.

## 우선순위 1: 생성 모델보다 먼저 채점기를 시험한다

관측 근거: 현재 dSprites Single Non-Atomic 판독기는 정답 target의 모든 속성을 물체별로 맞히는 정확도가 validation 100%, 공식 test 18.275%다. 실제 학습 풀에 없던 조합 13,261개 물체에서는 1.97%이고, 그 예측의 92.76%가 학습 지원 조합으로 돌아간다. 이것은 깨끗한 정답 그림에 대한 점수다. 생성 그림이 틀렸다는 증거와 혼동할 수 없다. [전체 사후 진단](r5/READER_DISTRIBUTION_AUDIT_KO.md)

가설은 “측정기의 조합 일반화 실패가 생성기의 의미 성능을 왜곡할 수 있다”이다. 현재 수치의 원인을 단정하기보다, 별도 자료에서 채점기 학습 지원을 통제한다.

| 통제 요소 | 다음 실험 |
|---|---|
| 자료 후보 | 공식 [SVIB Omni-Composition](https://systematic-visual-imagination.github.io/)의 짝 없는 장면. 먼저 실제 메타데이터/라이선스/중복을 감사한다. 제공되지 않는 정답 정보를 있다고 가정하지 않는다. |
| 동일·다른 정보 | primary 생성 모델은 그대로 고정한다. 측정기에만 추가되는 장면·속성 감독·정답 중심 정보를 명시한다. |
| 비교 | 현재 제한된 조합 학습 판독기, 전체 조합을 균형화한 판독기, dSprites의 알려진 renderer 기반 비학습 참조. renderer 참조는 특권 정보를 쓰는 진단이며 일반 사진 평가기가 아니다. |
| 분리 | 원본/회전 이미지 가족을 학습·보정·새 확인으로 나눈다. 기존 공식 test와 동일한 이미지 가족은 새 판독기 학습에서 제외한다. 조합 지원과 크기/가림/위치를 교차해 기록한다. |
| 관측 진단 | 속성별 혼동 행렬, 새 조합 정확도, 같은 그림의 작은 경계·위치 변화에 대한 일관성, 거짓 수락/거짓 거절을 계산한다. 단순 전체 정확도만 쓰지 않는다. |
| 새 진행 기준 제안 | 독립 확인의 각 주요 조합·크기·가림 군에서 깨끗한 target 전체 속성 정확도 95% 이상, 잘못된 속성을 의도적으로 넣은 그림의 거짓 수락 5% 이하. 희소 군은 분모를 공개하고 임의로 합치지 않는다. |
| 중단 | 위 기준을 만족하지 못하면 생성 의미 점수를 신뢰 가능한 정확도로 승격하지 않는다. 판독기 불일치 사례를 독립 사람 평가 대상으로 보존한다. |

이 기준은 다음 실험을 위한 제안이며 이번 평가 문턱을 바꾸는 것이 아니다. 기존 test를 본 뒤 만든 새 판독기로 기존 test를 다시 읽는 결과는 사후 진단으로 표시한다. 새 판독기 자체의 검증에는 별도 미사용 자료가 필요하다.

계산은 먼저 dSprites에서 판독기 후보 2개 × 100-update 시간 측정을 하고, 후보별 6,000-update 개발부터 시작한다. 현재 CPU 판독기 실측은 모델별 `r5/attributes/*/*/run.json`에 있다. 새 구조의 GPU/CPU 속도는 별도로 측정해 빠른 쪽을 선택한다. 개발 통과 전에는 3D 자료나 여러 seed로 자동 확장하지 않는다.

## 우선순위 2: 학습 잔차가 물리 계산을 망치는 조건을 찾는다

관측 근거: R3의 네 물체 61단계 위치 오차는 bounded 11.57px, contact+학습 잔차 6.02px, 학습 없는 coarse 물리 계산 2.62px였다. 같은 데이터로 인식·전이·디코더를 다시 학습한 원형 물체 통합에서도 contact 5.80px보다 coarse 3.33px가 낫다. 두 데이터의 수치를 한 모집단 평균으로 합치지는 않는다. [R3](r3/RESULTS_KO.md), [통합](r5/disks/RESULTS_KO.md)

가설은 “잔차가 접촉 순간의 적분 오차를 고치기보다 일반 운동에 불필요한 보정을 누적한다”이다. 이는 지금 결과에서 나온 검증 후보이며 아직 인과적으로 입증하지 않았다.

| 비교군 | 같게 유지할 것 | 달라지는 것 |
|---|---|---|
| coarse 물리 참조 | 상태·힘·행동·물체 반경·질량·자료 | 학습 없음 |
| 기존 contact residual | 같은 학습 장면·초기화·업데이트 | 현재 unrestricted 보정 |
| 접촉에 한정한 잔차 | 같은 신경망 파라미터와 학습 표본 | 접촉 거리로 정한 보정 적용 범위 |
| 크기 규제 잔차 | 같은 신경망 파라미터와 학습 표본 | 무보정으로 초기화하고 보정 크기를 규제 |

보정 적용 조건은 시험 오차를 보고 조정하지 않는다. 새 개발 validation에서만 선택하고 그 규칙을 잠근다. 처음에는 정답 초기 상태와 외력을 줘 인식 오류를 제거한다. 모든 군은 2물체 학습 → 2/3/4/6물체, 1/16/61/128단계, 충돌 없음/벽/물체 접촉, 행동 반전·외력 변경을 유지한다. 물리 사전 지식의 효과를 신경망 표현 효과라고 부르지 않는다.

새 진행 기준 제안: 네 물체 61단계에서 coarse 대비 위치 오차 10% 이상 감소, 비대상 반사실 반응 오차 5% 넘게 악화되지 않음, 기존 실패·관통·겹침 기준 유지, 두 물체 접촉군 16단계 1px 이하. 기존 bounded만 이기는 것으로 통과하지 않는다. 개발 4군 × 2,000업데이트에서 통과 후보가 없으면 접촉별 잔차 크기와 에너지·운동량 변화 분석으로 닫는다. 통과하면 기준 coarse와 선택 후보를 새 세 데이터 × 세 초기화로 확인한다. coarse는 학습 seed가 없으므로 9개의 독립 학습 모델로 세지 않는다.

여기서 배우는 보정이 알려진 simulator의 시간 적분 차이를 맞추는 데 그친다면 그 사실을 명시한다. 새로운 물리 법칙을 발견했다거나 실제 접촉 일반화를 증명했다고 하지 않는다. 반경·질량·반발 계수 변화는 별도 새 평가 축으로 사전 등록한다.

## 우선순위 3: 어떤 관측 정보가 장기 예측에 필요한가?

통합 실험에서 원형 물체 개수는 맞혔지만 61단계 상태+픽셀 동시 성공은 모든 물체 수에서 0%였다. 정답 미래 상태를 주면 신경 디코더 MSE는 훨씬 낮았다. 따라서 다음에는 인식기와 전이를 무작정 키우기보다 초기 위치·속도·합력·항력 오차를 하나씩 바꾸는 교체 실험을 확장한다.

1. 같은 원본 장면에서 관측 4/8/16프레임을 만든다. 프레임 수에 따른 추가 정보와 구조 변경을 분리한다. 동일 프레임 반복도 대조군으로 유지한다.
2. 점 추정과 상태 분포 예측을 비교한다. 가능한 여러 초기 상태/힘이 같은 관측에 맞는 경우 하나의 정답을 맞히는 점수만 요구하지 않는다. 예측 집합 포함률과 폭을 함께 기록한다.
3. 먼저 고정 전이·디코더에서 인식기만 바꾸고, 이후 공동 미세조정을 별도 군으로 둔다. 공동 학습 비용과 감독 추가를 표에 넣는다.
4. 평가 위치 오차는 모두 픽셀 단위로 환산하고 누락에 동일 벌점을 준다. 예측 분산을 크게 늘려 포함률만 올린 경우도 실패로 드러나게 한다.

일정한 중력과 바람의 합만 관측 가능한 설정에서 두 힘을 각각 알아냈다고 주장하지 않는다. 영구 가림에서 식별 불가능한 상태도 같은 원칙으로 다룬다. 새 진행 기준은 앞 단계에서 신뢰한 측정기와 전이 후보가 결정된 후 고정한다.

## 대칭성 비교는 R5의 결과에 따라 좁힌다

dSprites Multiple Non-Atomic에는 전체 회전으로 의미 라벨이 달라지는 규칙이 있다. 따라서 정확한 C4 구조를 모든 환경에서 강제하는 방식, 구조 없는 방식, 대칭을 적용할 조건을 구분하는 방식을 비교할 수 있다. 우선 같은 장면·규칙의 대칭 성립/불성립을 데이터 생성 정의에서 확인해야 한다. 단순한 data augmentation을 “대칭이 맞는 환경을 판별했다”는 증거로 쓰지 않는다.

이 방향의 직접 방법 비교는 기존 Aether 검토와 구별한다. Aether의 장 추정·국소 좌표 코드는 확인했지만 이번 OrbitLab 실행은 그 논문의 재현이 아니다. 입력·관측·감독·파라미터·업데이트·실시간 예산을 맞춘 뒤 직접 비교군으로 추가해야 한다. [본문·고정 코드 검토](references/METHOD_REVIEW_KO.md)

## 다음 단계에서 내놓을 결과물

현재 R5 최종 결과 → 새로운 사전 등록 → 한 개발 자료의 작은 비교 → 기준 통과 시 세 새 데이터/초기화 확인 → 전체 재생·실패 공개 순서를 유지한다. 실행 전에 데이터 seed의 기존 사용 여부와 회전/장면 가족 중복을 검사한다. 모델 seed만 바꾸어 새 자료라고 부르지 않는다.

실험마다 입력 정보표, 동일/추가 감독, 파라미터·업데이트·실제 초, 모든 실패 분모, 선택 당시 validation 파일 해시, 체크포인트와 재생 명령을 제공한다. 개선된 생성물이 실제로 확보되고 측정기의 한계가 확인된 뒤 출처를 가린 독립 사람 평가를 설계한다. 참여자 수·모델별 표본·장면 공유·응답 제외 기준을 사전에 고정하며, 사람을 모집하거나 참여했다고 가정하지 않는다.

현재 R5의 결과가 나오면 이 초안에서 **하나의 핵심 가설**을 주 연구로 선택한다. 모든 방향을 한 번에 확대하는 것보다 측정 오차 또는 접촉 잔차의 한 문제를 충분히 통제하는 편이 검토 가능한 결론에 가깝다.
