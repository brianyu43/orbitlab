# C07.4 집계 규칙: 같은 장면의 관측 길이 비교

2026-09-23. 관측 길이별 수치 결과를 선택하거나 모델을 조정하지 않고, 앞서 고정한 전체 평가 범위를 집계한다. 학습·평가 코드는 기존 설정으로 고정돼 있다.

- 원래 독립 데이터 생성 seed는 640031·997101·997102 세 개다. 길이 1·2·4·8과 초기화 0·1·2는 같은 데이터 안에서 교차한 조건이다.
- 같은 초기화·같은 장면끼리 길이를 비교한다. 비교 방향은 긴 길이에서 짧은 길이를 빼며, 가능한 여섯 쌍을 모두 남긴다. 오차는 음수, 성공률은 양수가 개선 방향이다.
- 각 초기화의 장면 평균을 구한 뒤 데이터 안에서 초기화 세 개를 평균한다. 마지막으로 독립 데이터 세 개를 같은 비중으로 평균한다. 데이터 사이 표준편차·범위·유효 데이터 수를 기록하며 아홉 개의 독립 실험이나 모집단 유의성으로 해석하지 않는다.
- 입력 길이별 서술 통계의 접촉 범주는 해당 길이에서 보이는 L−1개 과거 전이로 정한다. L=1은 빈 과거이므로 전부 과거 접촉 없음이다. 짧은 길이와 긴 길이의 서로 다른 접촉 집단을 같은 집단인 것처럼 비교하지 않는다.
- 길이 간 주 비교는 전체 장면이다. 접촉별 보조 짝 비교는 모든 길이에 동일한 t=0..7의 일곱 전이, 즉 L=8 기준의 고정 집단을 사용한다. 접촉 여부는 채점에만 쓰고 입력·추정·학습에 제공하지 않는다.
- 한 단계 추정·입력 교체의 모든 기존 요약 지표, 자율 예측의 모든 1/4/8/16/32/61단계 지표, 반대 행동·반응 지표를 보존한다. 물체 수·미학습 속성·외력의 원래 분할도 유지한다.
- 유한한 값의 평균에서는 사용한 장면 수와 전체 장면 수를 반드시 함께 남긴다. 길이 간 차이는 두 길이에서 모두 지표가 유한한 동일 장면에서 직접 차이를 계산한다. 각 길이의 전체 유한 사례 평균을 빼는 것으로 대신하지 않는다. 공통 집단의 좌·우 평균도 별도 보존한다.
- 공통 유한 집단의 오차 감소는 실패 감소와 같지 않다. 전체 장면을 분모로 한 수치 유한 비율·장면 성공률·실패 포함 지표를 함께 보고한다. 비유한 예측을 0 오차로 대체하거나 버린 뒤 전체 성공처럼 말하지 않는다.
- 빈 접촉 집단이나 공통 유한 장면이 없는 경우 평균은 결측이며 수는 0이다. 임의의 성공률·0 오차로 채우지 않는다.
- 원자료와 반복되는 긴 문자열을 수백만 CSV 행으로 복제하는 대신, 모든 값을 축이 명시된 압축 NPZ 블록과 JSON 색인으로 보존한다. 각 블록은 방식·환경·분할·운동 예측기를 고정하며, 길이·데이터·초기화·접촉 범주·지표 축과 출처 해시를 갖는다. 보고서의 표와 그림은 이 검증된 블록에서 추출한다.
- 집계는 모든 해당 데이터/길이의 재생 검증을 통과한 블록만 허용한다. 별도 검증기로 원자료의 장면별 값을 다시 읽어 평균·공통 집단·차이·분모·데이터 단위 집계를 확인한다. 정답 상태·환경 대조 및 정답 초기 정보 자율 예측은 길이가 달라도 동일한지 추가 확인한다.

집계 규칙과 구현 검사는 성능 결론이 아니다. C07 최종 완료에는 모든 길이의 평가·검증·보고, 환경 누락 및 식별 모호성 결과와의 종합이 필요하다. 외부 평가·선행연구 비교·사람 판정·최종 연구 묶음도 별도로 남아 있다.
