# 최종 감사와 별도 재현 묶음

원래 `RELEASE_MANIFEST.json`의 1,324개 파일과 후속 연구 산출물을 함께 담은 **로컬 보관용 재현 ZIP**을 만든다. 원래 배포 파일을 수정하거나 인터넷에 게시하지 않는다. 선행연구 원문·외부 예제는 출처와 기존 라이선스를 그대로 보존하며, 이 개인 보관 묶음 자체가 재배포 허가를 뜻하지 않는다.

1. `PLAN_KO.md`의 모든 ID와 완료 증거를 대조한다. 각 항목의 실제 범위, 검증 파일, 남은 부분을 표로 공개한다. 사람 응답이 없으면 A04는 미완료로 유지한다.
2. 수치 보고서와 그림의 원자료 연결, 재생 검증 범위를 확인한다. 일부 표본의 재현을 전체 학습 재현이라고 부르지 않는다.
3. 최초 원본 목록과 전체 SHA-256·바이트 수를 다시 확인한다. 후속 코드는 별도로 보관한다.
4. 원본 목록의 파일, `planning/`, 후속 코드·설정·데이터·checkpoint·원시 예측·보고서·실패 기록·공개 출처 자료를 수집한다. 가상환경, Python 캐시, macOS 메타데이터, 생성 중 임시 파일과 묶음 자신은 제외한다. 제외 목록을 기록한다.
5. 각 파일을 읽어 해시를 계산하며 ZIP에 넣고, 쓰는 도중 파일이 바뀌면 실패로 중단한다. ZIP 안의 모든 항목을 다시 읽어 별도 검증한다. 자동 검사 출력은 봉인한 ZIP 밖에 남긴다.
6. 새로운 임시 디렉터리에 풀어 전체 바이트와 해시를 다시 확인하고, 저장된 입력·checkpoint를 사용한 CPU 예측을 재계산한다. 경로가 바뀐 곳에서 검사한다. 전체 재학습·별도 하드웨어 재현은 실행한 경우에만 주장한다.

인수 조건은 ZIP 경로·크기·SHA-256, 전체 파일 무결성 검사, 다른 경로에서의 명시된 예측 재생 결과, 원본 불변 확인, 항목별 미완료 공개다. 실제 사람 판정은 코드나 자동 평가로 대신하지 않는다. 이 경우 재현 묶음은 만들어도 전체 목표는 완료로 표시하지 않는다.
