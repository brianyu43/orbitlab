# C04: 과거 영상에서 물체 상태와 환경을 추정하기

2026-09-23. C03의 정답 상태 한 단계 비교를 완료한 뒤 작성한 실행안이다. 이후 아래 1–6의 C04 학습·보류 평가와 예측 재생을 완료했다. 실행 결과는 [영상 추정 보고서](reports/dynamics_observation_eval_v1/RESULTS_KO.md)에 기록했다. 7의 긴 미래·행동 변경 연결은 C05/C06의 후속 작업으로 남아 있다. 기존 동역학 자료, 63개 상태 예측 모델과 결과는 보존한다.

## 비교할 질문

같은 네 장의 과거 RGB 관측만으로 마지막 상태와 환경의 식별 가능한 부분을 추정할 수 있는가? 정답 상태를 매 순간 제공한 C03의 효과가 영상 입력과 연속 예측으로 이어지는지는 별도 평가한다. 중력과 일정한 바람 가속도의 합이 관측에 나타나므로, 두 원인을 각각 알아냈다고 주장하지 않는다.

## 세부 실행 순서

1. **입력 계약과 누출 검사.** 기존 데이터의 네 관측 시점, 행동이 적용되는 시점, RGB/좌표 축을 코드와 재생으로 확인한다. 미래 frame/state, test의 정답 개수·ID·속도·환경은 추론 입력에서 제외한다. 행동은 관측 가능한 명령이므로 어느 단계에 제공하는지 고정한다.
2. **이미지 기준선.** RGB만으로 원형 물체 후보의 색·중심·크기를 추정하고 과거 네 장 사이의 대응을 만든다. 물체 수와 ID를 정답으로 제공하지 않는다. 겹침/접촉에서 합침과 추적 실패를 따로 기록한다. renderer의 원·색 규칙을 이용하는 기준선임을 명시한다.
3. **상태 판독 학습.** train의 속성을 감독 신호로 사용하는 이미지/짧은 시퀀스 판독기를 구현한다. 빈 자리, 위치·속도·크기·색·개수를 분리하고, 미래나 보류 조건으로 선택하지 않는다. 기존 도형의 판독기가 원형 운동 영상에도 그대로 통한다는 가정을 하지 않는다.
4. **환경 추론과 식별 한계.** 같은 네 관측만 사용하는 추론기를 비교한다. 합력·저항 계수의 정보가 충분한지 확인하고, 충돌·짧은 관측·거의 일정한 속도 때문에 구분하기 어려운 조건을 분리한다. 정답 위치/속도에서 환경만 추론한 대조군으로 시각 오류와 조건 추론 오류를 나눈다.
5. **성분별 대조.** 정답 상태+정답 환경, 추정 상태+정답 환경, 정답 상태+추정 환경, 추정 상태+추정 환경을 동일한 고정 transition에 연결한다. 정답 제공은 명시적 진단 대조군에만 사용한다.
6. **평가와 재생.** 상태의 개별 요인·대상 대응·환경 오차와 한 단계 출력 오차를 각각 보고한다. 학습과 다른 물체 수·속성·외력 조건도 같은 입력 길이와 slot 용량으로 평가한다. 장면/궤적을 재표집 단위로 하고 예측·정규화·자료 노출·모델 해시를 검증한다.
7. **C05/C06 연결.** 실제 추정한 마지막 상태와 환경을 한 번만 초기 입력으로 제공하고 긴 미래를 스스로 이어 예측하도록 연결한다. 행동 변경은 동일 과거에서 서로 다른 명령으로 비교한다. rollout 중 정답 상태·환경·물체 대응을 다시 공급하지 않는다.

## 시행 전 고정할 사항

실제 데이터 loader를 확인한 뒤 모델 용량, 감독 신호, train/validation 분리, 학습 예산, 초기화 수, 과거 관측 입력 형식과 평가 기준을 설정 파일에 고정한다. 이미지 기반 기준선의 규칙과 학습 모델의 물리 사전 지식을 각각 기록한다. 좋은 test 결과를 고른 뒤 이 문서를 사전 계획이라고 부르지 않는다.

동역학의 정답 상태 데이터와 모델은 입력 계약 확인과 개발 자료로 활용한다. 최종 독립 데이터 반복과 관측 길이·조건 누락 실험은 C07의 범위를 유지한다. 이 단계가 실패하더라도 다른 외부 과제와 문헌 비교의 요구를 줄이지 않는다.
