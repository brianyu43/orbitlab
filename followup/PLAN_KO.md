## 공통 규칙

- 각 실행은 새 출력 디렉터리와 잠긴 설정을 사용한다. 오류 수정 재실행은 기존 실패 로그를 남기고 별도 디렉터리에서 수행한다.
- 탐색과 확인 실험을 분리한다. 확인 실험의 test를 본 뒤 좋은 seed만 고르거나 종료 기준을 낮추지 않는다.
- 데이터 중복은 회전 궤도 기준으로 검사한다. 같은 장면의 네 회전과 같은 궤적의 프레임을 독립 표본으로 세지 않는다.
- 같은 step, 같은 계산 시간, 같은 파라미터 수를 서로 다른 비교로 보고한다. 모든 기준을 동시에 맞췄다고 주장하지 않는다.
- 사람 판정이 미수집이어도 코드·통제 실험·새 renderer 작업은 진행할 수 있다. 사람 검증을 요구하는 결론만 보류한다.
- 행동 계획과 실행 가능한 규칙 추론은 상위 제안서에서 선택 확장으로 두었다. C 단계 결과를 확인한 뒤 구체적 필요성이 생기면 별도 명시한다.
