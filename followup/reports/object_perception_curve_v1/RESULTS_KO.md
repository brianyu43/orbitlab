# 물체 인식 모델의 추가 학습 결과

2026-09-23. 기존 3,000-step 모델의 가중치·Adam 상태·학습 표본 난수·slot 초기화 난수를 이어서 6,000/12,000 steps까지 학습했다. 두 모델의 추가 학습은 각각 9,000 steps, 합계 18,000 steps다. 기존 pilot을 새 초기화로 대체하지 않았다. 아래는 초기화 하나, validation 128장에 대한 개발 진단이며 test/새 물체 수/가림 성적은 아직 열지 않았다.

| 모델 | 누적 학습 steps | 그림 전경 겹침 | 물체 영역 겹침 | 전경 ARI |
| --- | ---: | ---: | ---: | ---: |
| flat | 3,000 | 0.3924 | 0.0933 | 0.8121 |
| flat | 6,000 | 0.3709 | 0.1024 | 0.8422 |
| flat | 12,000 | 0.3968 | 0.1390 | 0.8142 |
| Slot Attention | 3,000 | 0.4551 | 0.0720 | 0.7659 |
| Slot Attention | 6,000 | 0.4835 | 0.0793 | 0.6830 |
| Slot Attention | 12,000 | 0.5226 | 0.0896 | 0.5912 |

그림 전경 겹침은 복원된 그림의 물체가 있는 부분을 정답 전경과 비교한다. 물체 영역 겹침은 출력 mask들을 실제 개별 물체와 가장 잘 대응시켰을 때의 IoU다. 둘 다 1이 완벽하지만 서로 다른 능력을 평가한다. ARI도 명령 성공률이나 정확도 백분율이 아니다.

Slot Attention은 그림의 대략적인 전경을 복원하는 점수가 올랐지만, 개별 물체를 찾는 점수는 여전히 낮았다. 예시에서는 각 slot의 mask가 넓은 배경까지 차지하고, 복원 도형의 모양도 둥글고 흐렸다. 전경 ARI는 오히려 낮아졌다. 따라서 학습 손실이나 그림 복원 하나만으로 물체 발견이 진행됐다고 판단할 수 없다.

같은 validation의 [단순 연결 영역 기준선](../object_component_diagnostic_v1/RESULTS_KO.md)은 정답 마스크 없이 물체 영역 겹침 0.9973을 얻었다. 이 쉬운 분리 조건에서 학습 모델의 실패는 상당하다. 반면 그 기준선은 맞닿은 물체를 합치는 실패가 있어 일반 객체 이해를 해결하지 않는다.

## 검증

네 체크포인트의 512개 validation 출력을 CPU에서 다시 계산했다. 부모 모델과 optimizer 해시, Adam step, 두 난수 흐름을 원래 seed부터 재생한 상태, 초기 가중치, 동일 학습 표본, 모든 평가 행과 평균을 검사했다. CPU/MPS 간 작은 부동소수점 차이는 기록했다. 12,000-step Slot Attention의 hard mask는 128×64×64픽셀 중 1픽셀에서 달랐고, 저장된 MPS mask를 기준으로 기존 지표를 재계산했다. [전체 검증](verification.json)

모델의 입력은 RGB이며 정답 마스크는 평가에만 사용했다. 두 모델은 같은 step·이미지·샘플링을 사용했지만 flat 216,324개/Slot Attention 148,100개로 파라미터 수가 다르며 계산 시간도 같지 않다. [원자료 집계](summary.json) · [Slot Attention 12,000-step 예시](../../runs/object_perception_curve_v1/slot_s0_step12000/val_examples.png)

## 다음 진단

1. 같은 체크포인트에서 encoder의 attention과 decoder의 mask를 따로 측정해, 분리 실패가 어느 단계에서 발생하는지 나눈다.
2. RGB에서 얻은 전경만 사용하는 공통 후처리를 두 모델과 기준선에 적용해 배경 누출의 영향을 측정한다. 원래 mask 지표를 덮어쓰지 않는다.
3. 입력 정규화·위치 표현·분리 구조의 변경은 각각 독립 실험으로 기록한다. 최종 설정을 잠근 뒤 보류한 test/물체 수/가림 조건과 이미지 개입으로 연결한다.

B04는 진행 중이다. 더 많은 steps에서 절대로 개선되지 않는다는 결론도, 현재 물체 표현이 충분하다는 결론도 내리지 않는다.
