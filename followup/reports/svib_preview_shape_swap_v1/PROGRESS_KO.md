# SVIB 공개 예제 후속 실험 완료

2026-09-23. 공개 preview 500쌍, 기준선 32조건, 24개 모델의 학습·평가와 별도 검증을 완료했다. 학습/검증/ID/공통 test의 예측 4,800개와 회전 입력 예측 7,200개를 재생하고 모든 픽셀 점수·집계·짝 비교·표·그림을 확인했다.

C4의 전체 test 픽셀 오차는 일반 모델보다 alpha 평균 4/4개와 초기화 짝 11/12개에서 작았다. 그러나 두 방법 모두 alpha 평균 4/4개에서 그대로 두기보다 오차가 컸다. 학습 이미지 오차는 작고 보류 이미지 오차는 크게 증가해 작은 예제에 대한 과적합이 드러났다. 회전 일관성을 외부 변환 규칙 이해로 해석하지 않는다.

B06의 축소 외부 과제 연결을 마친 상태다. 공식 전체 벤치마크·LPIPS·의미상 Shape-Swap 성공률·기존 OrbitLab checkpoint 전이는 실행하지 않았으며 달성 주장에 포함하지 않는다. 전체 후속 목표는 관측 길이 종합·전체 그림·최종 연구 메모·재현 묶음·실제 사람 판정이 남아 있다.
