# 단순 영상 처리 기준선이 알려준 점

2026-09-23. 현재 떨어진 두 물체 validation 128장을 대상으로 한 진단이다. 학습 모델의 최종 성적이나 이미지 편집 성적은 아니다.

입력 RGB에서 밝기가 0.05보다 큰 픽셀의 연결 영역을 찾고, 각 영역의 자체 밝기를 기준으로 흐린 경계를 잘랐다. 정답 마스크, 실제 물체 수, 색상표, 물체 위치를 입력하지 않았다. 최대 네 물체라는 과제의 용량만 사용했다. 설정은 실행 전에 저장했고 정답과 맞춰 기준을 조정하지 않았다.

| 지표 | 연결 영역 기준선 |
| --- | ---: |
| 물체 영역 겹침, 1이 완벽 | 0.9973 |
| 전경 ARI | 1.0000 |
| 전체 픽셀 ARI | 0.9986 |
| 보이는 물체 수 일치 | 128/128 |

같은 validation에서 3,000-step 학습 모델의 물체 영역 겹침은 flat 0.0933, Slot Attention 0.0720이었다. 따라서 이 쉬운 분리 조건에서는 정답 마스크 없이도 매우 정확하게 영역을 찾을 수 있다. 학습 모델의 실패를 데이터의 본질적 식별 불가능성으로 설명할 근거는 없다. 더 오래 학습하는 곡선과 모델의 분리 방식을 진단해야 한다.

연결 영역 방법은 붙어 있는 두 물체를 하나로 합칠 수 있다. 실제로 맞닿은 빨강/초록 사각형 예제에서 한 물체로 합치는 실패를 검증했다. 가림, 같은 색, 복잡한 배경에 일반화하는 물체 표현을 얻었다는 뜻이 아니다. 현재 쉬운 데이터의 높은 점수만으로 새로운 객체 표현 연구의 기여를 주장할 수 없다는 대조군으로 남긴다.
