# RGB 물체 표현의 두 차례 개발 학습

2026-09-23. 정답 마스크·속성을 훈련 입력이나 손실에 주지 않고, RGB 복원만으로 학습했다. 각 버전에서 flat/Slot Attention 모델 한 개씩 학습했으며 validation 128장만 평가했다. B04 전체 완료나 독립 test 성능으로 취급하지 않는다.

첫 버전은 1,000 steps에서 두 모델 모두 검은 배경으로 붕괴했다. foreground MAE는 0.452, 복원 전경 IoU는 0이었다. 코드와 체크포인트·평가를 보존했다.

두 번째 버전은 sigmoid 대신 선형 RGB 출력과 입력 밝기로 계산한 전경/배경 균형 손실을 사용하고 3,000 steps 학습했다. 두 수정과 학습량 증가가 함께 있으므로 각각의 원인 효과를 분리한 비교는 아니다. 같은 버전 안에서는 두 모델의 이미지·샘플 순서·학습 step·slot 용량을 맞췄다. 파라미터는 flat 216,324개, Slot Attention 148,100개이며 시간/파라미터를 같게 맞춘 비교는 아니다.

| Validation 지표 | Flat | Slot Attention |
| --- | ---: | ---: |
| 복원 전경 MAE, 낮을수록 좋음 | 0.154 | 0.122 |
| 복원 전경 IoU, 높을수록 좋음 | 0.392 | 0.455 |
| 전경 ARI, 물체 전경끼리의 분리 | 0.812 | 0.766 |
| 전체 픽셀 ARI, 배경도 포함 | 0.002 | 0.009 |
| 물체와 slot의 일대일 대응 mask IoU | 0.093 | 0.072 |
| 3,000-step 학습 시간, 기록값 | 167초 | 182초 |

복원 전경 IoU와 slot의 대응 mask IoU는 서로 다른 지표다. 전자는 합친 출력 그림이 원래 전경을 얼마나 복원하는지, 후자는 개별 slot이 실제 물체 영역을 얼마나 맡는지를 본다.

출력 그림은 첫 버전보다 개선됐지만 여전히 흐린 색 덩어리에 가깝다. 각 slot의 mask에는 넓은 배경 영역이 섞여 있다. 전경만 떼어 보면 두 물체가 다른 영역에 들어가 ARI가 높아질 수 있으나, 실제 물체 윤곽을 분리했다는 의미는 아니다. 낮은 대응 mask IoU와 실제 mask 그림을 함께 보고 물체 발견 성공을 주장하지 않는다.

두 버전의 모델 4개에 대해 체크포인트·데이터·집계 해시를 확인했다. 저장된 mask에서 지표를 다시 계산하고 RGB 예측을 CPU에서 재생했다. 두 번째 버전의 CPU/MPS 최대 이미지 오차는 0.0002 미만이고 hard mask 불일치는 0이었다. 검증 통과는 산출물의 일관성을 의미하며, 낮은 모델 품질을 통과 처리하는 기준이 아니다.

## 이어서 할 작업

1. 같은 v2 체크포인트와 optimizer/RNG를 보존해 더 긴 학습 곡선을 측정한다. 처음부터 다시 학습해 이전 계산을 버리지 않는다. validation으로 수렴·mask 상태를 보고, test는 최종 프로토콜을 고정한 후 평가한다.
2. 전경·배경 손실, mask의 영역과 slot별 RGB를 따로 진단한다. 전경 ARI 하나로 다음 단계 진입을 판단하지 않는다. 필요한 구조 변경은 별도 버전과 동일 조건 비교로 기록한다.
3. 물체 표현이 확보되면 속성 판독과 이미지 입력의 개입을 연결한다. 지도학습 probe를 쓰는 부분은 비지도 표현 학습과 나눈다. 물체 수·가림·같은 색 물체는 각기 다른 실패 조건으로 평가한다.
4. 독립 반복, 외부 SVIB와 환경 조건·미래 예측은 전체 계획에 그대로 남아 있다.
