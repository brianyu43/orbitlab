# OrbitLab의 선행연구 겹침과 주장 범위

2026-09-23. 기존 다섯 방법의 본문·핵심 구현 비교에, 외력·부분 대칭·변경 영역 예측을 직접 다루는 네 연구를 추가했다. 지정한 가까운 방법에 대한 비교 기록을 완성했으며, 모든 문헌을 망라하거나 연구의 독창성을 증명한 것은 아니다. 원문과 공개 코드를 읽었고 타 방법의 전체 학습은 실행하지 않았다.

현재 OrbitLab은 **대칭 제약의 이득을 입력 정보·인식 오차·예측 시간에 따라 나누어 보는 통제 실험 묶음**으로 설명하는 것이 타당하다. 물체별 표현, 외력 추정, 부분 대칭, 명령에 따른 조작 각각을 처음 제안했다는 설명은 근거가 없다. 새로운 고성능 세계 모델도 아직 입증하지 못했다.

## 가장 가까운 방법과 실제 차이

| 방법 | 원문에서 확인한 핵심 | OrbitLab과 겹치는 점·차이 |
| --- | --- | --- |
| Slot Attention | 경쟁 attention과 공유 갱신으로 RGB feature를 물체별 slot에 할당한다. | slot 분리와 공유 decoder는 기존 방법이다. 우리 RGB 실험은 축소 구현·다른 손실의 진단이며 원저자 성능 재현이 아니다. |
| Invariant Slot Attention | 물체 위치·크기·방향에 상대적인 좌표를 attention과 decoder에 제공한다. | 물체와 기하학적 대칭을 함께 다루는 것 자체는 새롭지 않다. 추정한 물체별 방향과 정확한 전역 C4 작용의 보장을 구분해야 한다. |
| SysBinder | 물체 slot 내부를 factor block으로 나누고 block별 갱신과 prototype memory를 쓴다. | 물체 분리와 속성 분리는 별개다. 높은 probe 점수만으로 독립적인 개념 조작을 주장할 수 없다. |
| Dreamweaver | 영상에서 recurrent block-slot을 유지하며 미래 토큰을 예측하고 조합을 바꾼다. | 물체·속성·운동의 재조합은 기존 목표다. 편집할 block을 식별할 때 쓰는 정답 기반 분석과 표현 학습 입력을 나눠 비교해야 한다. |
| SEN | 영상 관측을 알려진 군 작용을 갖는 표현으로 보내고 equivariant transition을 학습한다. | 대칭 표현을 세계 모델에 넣는 것 자체는 기존 방법이다. 현재 OrbitLab의 픽셀 생성·상태 감독 손실과 수치를 직접 비교할 수 없다. |
| Aether, NeurIPS 2023 | 관측 궤적에서 전역 외력장을 추정해 국소 좌표의 물체 상호작용과 결합한다. 입력 계마다 달라지는 장은 잠재 요약과 FiLM으로 조건화한다. | **숨은 외력과 equivariant dynamics의 결합은 직접 겹친다.** 우리는 단순한 일정 합력·저항의 제공/추정/누락과 RGB 관측 길이를 통제했다. 일반 공간 외력장 학습에서 우월하다는 증거는 없다. |
| PEnGUiN, 2025 | equivariant·일반 GNN 경로를 입력에 의존하는 symmetry score로 혼합하고 부분 대칭을 분류한다. | ‘대칭이 맞는 정도에 따라 완화한다’는 주장도 기존에 있다. OrbitLab의 고정 비교 모델은 이 입력별 혼합 구조를 재현하지 않았고 MARL 정책 성능도 평가하지 않았다. |
| PE-RL, arXiv v2 / ICLR 2026 | equivariant·일반 한 단계 예측기의 불일치로 국소 대칭 위반을 찾아 Bellman 갱신과 정책을 선택한다. | 잘못된 대칭의 오차와 이를 선택적으로 피하는 전략이 겹친다. OrbitLab은 영상 추론·자율 rollout의 오차를 측정했으며 가치 함수·정책 최적화 결과는 없다. |
| Modeling What Changes, arXiv v1, 2026-09-02 | 구조화된 물체 상태에서 변경 gate와 잔차를 예측하고 나머지를 복사한다. 실제 변경 물체와 비변경 물체의 점수를 나눈다. | 비대상 보존·무변화 대조·oracle로 원인을 나누는 평가가 직접 관련된다. 논문도 변경 물체의 운동 예측과 긴 rollout의 한계를 명시한다. 우리의 RGB 인식 병목과 구조화 상태의 성공을 합쳐 주장해서는 안 된다. |

앞의 다섯 방법에 대한 절 번호와 구현 기록은 [첫 비교 기록](NEAREST_METHODS_REVIEW_KO.md)에 있다. 추가 네 방법은 아래 출처와 구현 확인으로 연결된다.

## 외력과 대칭에 대한 직접 겹침

Aether의 §3.1–3.3은 고정된 전역 장의 영향과 상대적인 물체 상호작용이 함께 관측되는 경우를 다룬다. 추정한 힘을 벡터 상태에 추가하고 국소 좌표로 변환한다. §3.2의 dynamic field는 입력 계별 장의 잠재 요약을 사용한다. 따라서 힘을 벡터처럼 변환하거나 관측 운동에서 힘을 추정한다는 사실만으로 OrbitLab의 독창성을 주장할 수 없다. [논문](https://arxiv.org/abs/2310.20679) · [공식 구현](https://github.com/mkofinas/aether)

고정 commit `f88cac1611d9fd8400d0ce8ae4333c936cf09022`의 `AetherLocalizer.canonicalize_inputs`와 `create_edge_attr`에서 속도와 힘을 함께 회전시키는 것을 확인했다. `Aether.forward`는 field network의 출력 힘을 상태에 붙여 GNN으로 보낸다. `DynamicFieldAether`의 별도 state-to-state 구현은 `GraphSummary`와 `FilmedNetwork`를 사용한다. 이 state-to-state 참조가 논문의 모든 sequence 모델·실험 설정과 같다고 가정하지 않았다.

PEnGUiN §4–6은 일반/대칭 경로의 혼합과 입력별 점수 추정을 제시하고, 센서 편향·안전 영역·대상 관련성 등의 비대칭 조건을 비교한다. 확인한 본문은 arXiv v1이다. 공식 학술 페이지에서도 같은 방법의 출판을 확인했지만, 이번 검색과 본문에서 저자 공식 구현 주소를 확인하지 못해 코드 검토를 했다고 표시하지 않는다. [본문](https://arxiv.org/html/2503.15615v1) · [RLJ 출판 기록](https://rlj.cs.umass.edu/2025/papers/Paper310.html)

PE-RL v2의 §4–6은 국소 대칭 위반에 따른 Bellman 오차와 예측기 불일치를 이용한 gate를 구분한다. 본문의 이론은 제시된 MDP·유계 보상·gate 조건에 관한 것이며, 불완전한 RGB 관측에서 물리가 식별된다는 보장이 아니다. 저자 프로젝트의 구현 링크는 확인 시점에 `Code (Coming Soon)`이었다. 이 연구의 구현이나 저자 성능을 재현하지 않았다. [본문](https://arxiv.org/html/2512.00915v2) · [저자 프로젝트](https://pranaboy72.github.io/perl_page/)

## 변경과 보존을 나누는 평가의 겹침

Modeling What Changes §III, §IV, §IX와 Appendix F를 확인했다. 물체 상태와 action을 입력하고 정답 변경 mask로 gate를 감독한다. 원문은 구조화 상태와 픽셀 인식의 차이, no-op 대비 변경 물체 예측의 한계, 일부 대조군·평가 정의의 한계도 설명한다. 이 논문의 상대적인 dense baseline 개선을 완성된 물리 예측 능력으로 옮겨 말할 수 없다. [원문 v1](https://arxiv.org/html/2609.02046v1)

공식 저장소의 기본 branch는 `master`였으며 commit `69d559263dbd5a1aaac57697471c8517fdeb00d5`를 고정해 읽었다. `SparseResidualHead.forward`의 gate×delta와 `sparse_residual_loss`의 정답 변경 mask 감독, oracle 진단의 predicted-gate / true-gate / no-op 분리를 확인했다. 현재 코드에는 확률적 잔차 head와 추가 split 옵션도 있어 논문 v1의 실험과 현재 저장소의 모든 기능을 동일시하지 않았다. 저장소 주석에 적힌 데이터 문제의 수치는 우리가 원데이터로 재검증한 결과가 아니므로 비교 성능 주장에 사용하지 않았다. [공식 코드](https://github.com/ParamThakkar123/sparse_world_models)

## 무엇을 주장할 수 있는가

| 주장 후보 | 현재 판단 | 근거 또는 아직 필요한 증거 |
| --- | --- | --- |
| 대칭·물체·외력·조작을 처음 결합했다 | 지지되지 않음 | 위의 직접 관련 연구들과 넓게 겹친다. 요소를 나열하는 것으로 독창성이 생기지 않는다. |
| 공동 회전 제약이 한 단계 예측에 이득을 준다 | 현재 simulator의 검증된 경험적 결과 | 독립 데이터 3묶음에서 일반 interaction 대비 이득을 확인했다. 알려진 물리 참조보다 우월하다는 결과는 없다. |
| 환경 정보가 없을 때 구조의 우열이 달라진다 | 현재 조건의 검증된 진단 | 합력을 숨긴 108조건 비교와 동일 함수·대응 가중치 검사를 완료했다. 임의 환경에서의 최적 오차 법칙은 아니다. |
| 더 긴 관측이 정보 부족과 학습 실패를 구분한다 | 집계와 해석 진행 중 | 같은 마지막 시점·행동·미래의 1/2/4/8장 실험을 수행했다. 전체 재생·짝 비교가 끝나기 전 효과를 확정하지 않는다. |
| 대칭만으로 외부 변환 규칙을 일반화한다 | 이번 축소 실험에서 지지되지 않음 | SVIB preview의 C4는 일반 모델보다 대체로 좋았지만 네 alpha 평균 모두 identity보다 전체 오차가 컸다. |
| 관측 정보×올바른 대칭×예측 길이의 실패 경계를 재현 가능하게 정리했다 | 최종 연구 메모의 중심 후보 | 관측 길이 종합과 전체 그림·재현 묶음이 남았다. 별도의 새 아키텍처 또는 전역 독창성 증명은 아니다. |

후속 논문 수준의 방법 개선을 선택한다면 Aether형 field 경로, PEnGUiN형 입력별 혼합, 부분 관측에서 여러 미래를 유지하는 예측을 **동일한 입력 정보와 계산 예산**으로 비교할 필요가 있다. 이는 현재 계획의 결과를 바탕으로 선택할 다음 연구 제안이며, 이번 실행에서 재현·달성한 결과가 아니다. 외부 예제에서 실패한 모델을 곧바로 큰 자료에 확장하기 전에는 학습 자료와 보류 자료의 격차, 변경 영역과 보존 영역의 손실을 먼저 검토해야 한다.

## 검토 범위와 출처 보존

현재 검토는 물체 표현·기하학적 편향·숨은 외력·부분 대칭·변경 예측에 직접 가까운 위 아홉 방법에 한정한다. 부분 관측 RL 등 인접 문헌의 존재도 확인했으므로 ‘부분 관측과 대칭의 결합이 최초’라는 주장 역시 하지 않는다. 학술적 관심이나 특정 연구실의 채택·지지를 추정하지 않았다.

`references/nearest_methods_v2/manifest.json`에 받은 URL, SHA-256, 고정 코드 commit과 실패한 조회를 기록했다. Hugging Face의 PE-RL 본문/메타데이터는 404여서 버전이 지정된 arXiv 원문을 사용했다. Sparse World Models의 `main` 조회도 404였으나 저장소 메타데이터에서 `master`를 확인한 뒤 실제 코드를 읽었다. 원본 논문·코드는 참조 자료이며 새 재현 배포물에는 허가 없이 묶지 않는다.
