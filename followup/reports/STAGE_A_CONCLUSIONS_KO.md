# 단일 도형 단계의 원인 분석

2026-09-23. 자동 평가와 통제 실험에 근거한 중간 결론이다. 사람 판정 A04는 남아 있으며 전체 연구 목표는 계속 진행한다.

## 확인된 효과

동일한 C4 AE 위에서 생성기만 바꾸면 정확한 C4 flow의 자동 평가 이점이 유지된다. 새 데이터 생성 seed 3개 × 초기화 3개에서 엄격한 도형 기준과 모양·색을 함께 만족한 비율은 일반 flow 3.3%, C4 flow 15.6%였다. 일반 flow를 같은 시간만큼 더 학습해도 5.3%였으며 9개 짝 비교 모두 C4가 높았다. AE, 초기 raw flow 가중치, 학습 latent, 생성 noise를 맞췄다. [반복 집계](confirmation_v1/summary.json), [검증](confirmation_v1/verification.json)

이는 이 단일 도형 과제에서 flow의 회전 제약이 도움이 된다는 증거다. 원래 B1과 B2 전체의 차이를 모두 이 원인 하나로 설명하지는 않는다. 독립 데이터 seed는 3개이며, 추론 비용은 맞추지 않았다. 이전 측정에서 C4 생성은 일반 flow보다 약 2.7배 느렸다.

## 평가 기준을 정정했다

기존 IoU 0.65 기준은 원·사각형·무작위 잡음을 통과시켰다. 새 calibration과 독립 대조 test로 기준을 보정했다. 예전 52.2%를 고품질 생성 성공률로 부를 수 없다. 같은 원래 B2 표본의 보정 후 값은 16.6%이고, 새 데이터 반복의 값은 15.6%다. 보정된 자동 기준 역시 사람 품질 평가를 대체하지 않는다. [보정 결과](evaluator_calibration_v1/summary.json)

## 그림을 만드는 부분에도 병목이 있다

같은 encoder를 고정하고 decoder를 새로 학습했다. 두 방식은 파라미터 수, 초기 가중치, 학습 장면·latent·표본 순서, 6,000 steps를 맞췄다. 한 방식은 각 방향 출력을 sigmoid로 픽셀값으로 바꾼 후 평균하고(pixel mean), 다른 방식은 sigmoid 이전 값을 평균한 뒤 픽셀값으로 바꾼다(logit mean). 둘 다 정확한 C4 회전 관계를 유지한다.

| 입력과 측정 | Pixel mean | Logit mean |
| --- | ---: | ---: |
| 학습된 표현에서 test 복원 mask IoU | 0.843 | 0.893 |
| 학습된 표현에서 test 복원 엄격 기준·모양·색 통과 | 73.7% | 83.5% |
| 정답 상태에서 test 복원 엄격 기준·모양·색 통과 | 43.9% | 86.7% |
| 동일한 flow 생성 latent에서 본 조합 엄격 기준·모양·색 통과 | 17.4% | 21.5% |
| 동일한 flow 생성 latent에서 제외 조합 엄격 기준·모양·색 통과 | 9.0% | 13.2% |

원래 decoder의 동일한 flow 표본 결과는 본 조합 16.2%, 제외 조합 10.8%였다. 원래 decoder는 AE와 함께 학습됐고 새로운 두 decoder는 고정 encoder 위에서 추가 학습됐으므로, 원래 모델과의 비교는 학습 이력이 다른 참고값이다. 엄밀하게 통제된 쌍은 새 pixel/logit decoder다.

또한 새 pixel/logit decoder의 모양·색 일치는 본 조합 58.1%/57.4%로, 윤곽 선별 지표와 달리 개선되지 않았다. 그릴 방식을 바꾸는 것만으로 원하는 모양을 선택·생성하는 문제는 해결되지 않았다. 복원 시의 높은 성적과 생성 시의 낮은 성적 사이에 여전히 큰 차이가 있다. 정답 상태 oracle도 학습된 decoder를 사용하므로 완벽한 renderer 상한이 아니며 최적화와 구조의 영향을 받는다.

학습 12개, 복원 지표 집계 216개, C4 수치 오차, frozen AE와 가중치·자료 짝맞춤을 검사했다. 생성 transfer는 같은 저장 latent 576개 × 3 초기화 × 3 decoder를 썼으며 새 flow 학습은 하지 않았다. 이 decoder 실험은 기존 진단 pool과 평가 noise를 재사용한 탐색이다. 새 데이터에서 확인한 15.6%와 개발 결과 21.5%를 직접적인 성능 상승 곡선으로 합치지 않는다. ## 표현에서 확인된 것과 남은 것

모양은 단순 선형 판독기로 45.4%, 비선형 판독기로 75.0% 읽혔다. 따라서 모양 정보가 전혀 없다고 단정할 수 없지만, 독립적으로 편집 가능한 개념이 됐다고 결론 낼 수도 없다. 네 묶음은 네 물체가 아닌 네 회전 방향이다. [표현 진단](probes_6000_v1/summary.json)

회전 불변 표현의 공통 복원에 대한 표준 MSE 하한을 별도로 유도·확인했다. 이것은 새로운 정리가 아니며 전체 C4 표현의 생성 오류 원인 전체를 설명하는 하한도 아니다. [하한 설명](invariant_bound_v1/EXPLANATION_KO.md)

## 다음 단계에 가져갈 선택

1. 단일 물체 실험의 기준은 독립 반복을 마친 C4 AE+flow로 유지한다. logit mean은 유망한 decoder 탐색 결과로 보관하며 새 데이터 확인을 거친 최종 개선 모델로 부르지 않는다.
2. 여러 물체 단계는 정답 상태를 주는 비교와 RGB에서 물체를 찾는 비교를 분리한다. 방향 묶음을 물체 묶음으로 해석하지 않는다.
3. 상태가 이미 주어진 단순 개입에서 물체별 공유 규칙의 효과를 확인했으므로, 다음 병목은 물체 분리와 속성 판독이다. RGB만으로 이를 평가한 뒤 환경 조건·미래 예측으로 확장한다.
4. 사람 평가, 외부 SVIB 모델 결과, 동역학, 가까운 연구와의 본문·코드 비교, 최종 재현 묶음은 남아 있다.
