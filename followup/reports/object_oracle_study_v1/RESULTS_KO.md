# 정답 물체 상태를 준 개입 실험

2026-09-23. 학습 6회와 예측 재생 검증을 완료했다. 이 실험은 물체의 성질과 위치를 이미 알고 있을 때 적용할 규칙을 배우는 문제다. 이미지에서 물체를 알아보는 능력은 포함하지 않는다.

## 무엇을 비교했나

두 모델에 같은 입력을 주었다: 최대 네 물체의 모양·색·좌표·크기·방향·존재 여부, 바꿀 물체 표시, 색/회전/이동 명령이다. 한 모델은 네 물체 상태를 한 벡터로 합쳐 처리하고(flat), 다른 모델은 같은 신경망을 각 물체에 적용한다(object). 두 모델 모두 모든 물체의 변화량을 예측한다. 비대상 물체를 무조건 보존하는 정답 규칙을 학습 모델에 넣지 않았다.

각 모델의 학습 파라미터는 정확히 34,991개다. 같은 task 표본, 같은 자리 섞기, 같은 optimizer와 손실, 6,000 steps를 사용했다. 구조가 다르므로 초기 가중치 자체가 같지는 않다. 3회 초기화를 비교했으며, 데이터 생성 seed는 하나다. CPU에서 실행했고 계산 시간까지 같게 맞췄다는 주장은 하지 않는다.

학습 장면에는 두 물체가 있다. 빈 자리까지 포함한 네 자리 전체를 매번 섞어, 모든 자리에 물체와 목표 명령이 충분히 나타나게 했다. 색 변경·90도 회전·이동은 각각 학습했지만, 색 변경 뒤 회전하는 쌍은 학습에서 제외했다. 조합 평가는 같은 모델을 두 번 연속 적용하며, 중간 정답 상태를 넣지 않는다.

## 결과

아래는 **목표 변경 + 목표의 나머지 속성 보존 + 비대상 보존 + 빈 자리 보존**을 모두 만족한 비율이다. 범주형 속성은 정확한 일치, 좌표는 각 축 1픽셀 이내, 반지름은 0.5픽셀 이내를 요구했다. 장면별 평균을 구한 뒤 3회 학습을 평균했다.

| 평가 조건 | 장면 전체를 한 벡터로 처리 | 물체별 공유 모델 |
| --- | ---: | ---: |
| 두 물체, 일반 test | 99.54% | 99.93% |
| 두 물체, 학습에서 제외한 모양·색 조합 포함 | 98.83% | 100.00% |
| 세 물체 | 10.74% | 100.00% |
| 네 물체 | 0.78% | 100.00% |
| 가려진 두 물체, 정답 상태 제공 | 100.00% | 100.00% |

두 물체의 미학습 조작 합성은 두 모델 모두 100%였다. 따라서 조작 합성 자체에서 두 방식의 차이가 있다고 주장하지 않는다. 차이는 주로 물체 수를 늘린 조건에서 발생했다. 세 물체에서 flat의 목표 변경 성공률은 86.8%지만 비대상 보존은 29.4%여서, 목표만 채점하면 문제를 놓친다.

이 전체 성공률은 허용 오차에 민감하다. 사후 민감도 검사에서 좌표/반지름 허용치를 1/0.5픽셀에서 2/1픽셀로 늘리면 flat의 세 물체 성공률은 10.7%에서 52.5%, 4/2픽셀에서는 91.6%가 된다. 세 물체의 목표 좌표 평균 절대 오차는 flat 0.84픽셀, object 0.05픽셀이고, 비대상 좌표 변화는 각각 0.60픽셀과 0.04픽셀이다. 따라서 수치는 작은 위치·크기 오차의 누적과 함께 해석해야 한다. 고정한 주요 기준을 바꾸지는 않았다. [허용 오차 민감도](tolerance_sensitivity.json)

가림 조건에서도 정답 상태를 모두 제공했으므로, 그 조건의 100%는 가려진 물체를 이미지로 알아냈다는 뜻이 아니다. 물체별 공유 모델은 다른 물체를 입력으로 받지 않으므로 물체 수 변화에 덜 영향을 받는 것이 이 설계에서 예상되는 성질이다. 충돌처럼 물체 사이 상호작용이 필요한 과제의 우위를 뜻하지 않는다. 단순한 독립 개입의 구현 확인과 지각 단계의 기준선으로 사용한다.

아무것도 바꾸지 않는 identity 기준선의 전체 성공은 0%, 명시적인 정답 규칙을 실행한 analytic 기준선은 100%였다. 후자는 학습 결과가 아니다.

## 검증과 다음 단계

기본 장면 1,792개와 원래 개입 쌍 4,820개를 전부 renderer로 재생했다. 물체 수·가림 조건용 명령을 추가한 task 집합은 6,356개다. 정답 변환을 별도 수식 구현으로 전부 확인했고, 6개 모델과 2개 기준선의 평가 예측 26,272개를 재생했다. 2,304개 장면 단위 지표 집계, 같은 학습 표본과 자리 노출, 모델 해시 검사를 통과했다. 물체별 모델의 자리 순서에 대한 일관성도 확인했다.

다음 단계는 RGB만 입력받아 물체를 나누고 표현하는 모델이다. 정답 마스크는 훈련 입력과 손실에 넣지 않고 평가에만 사용한다. 여기서 물체를 잘못 나누거나 속성을 잘못 읽으면, 본 실험의 높은 수치를 전체 시스템의 능력으로 옮겨 말할 수 없다.
