# 후속 연구 진행 기록

2026-09-23 · 전체 목표는 진행 중이다. 여러 물체·외부 벤치마크·동역학·최종 배포는 아직 완료하지 않았다.

작업표 31개 항목 중 완료 21개, 진행 중 3개(SVIB·문헌 비교·핵심 그림), 사람 판정 대기 1개, 후속 대기 6개. 이 수는 모델의 능력이나 연구 완성도를 뜻하지 않는다. 현재 능력의 쉬운 설명과 최신 수치는 `CURRENT_CAPABILITY_KO.md`에 있다.

## 실제로 수행한 작업

- 기존 배포 자료 1,324개 파일의 해시 일치를 시작과 이번 중간 감사에서 확인했다.
- 평가기 스트레스 검사 8,192행과 음성 대조 128개를 만들었다. 회전/변형을 공유하므로 8,192개 독립 장면으로 세지 않는다.
- 새 calibration과 독립 test로 자동 거절 기준을 보정하고, 기존 6개 생성 모델의 표본 3,456개를 재평가했다.
- 6,000-step AE 6개의 내부 표현과 새로운 복원 평가 장면을 검사했다.
- 같은 C4 AE에서 flow만 바꾼 고정-step 9회와 같은 시간 9회, 총 18회 학습을 마쳤다.
- 불변 표현의 표준 MSE 하한을 새 512개 장면에서 확인했다.
- 출처를 가린 사람 판정용 생성물 240장을 준비했다. 실제 사람 응답은 아직 없다.

## 평가기에 관한 중요한 정정

기존 template IoU≥0.65 조건은 원·사각형·무작위 잡음을 각각 32개 전부 통과시켰다. 따라서 기존 “유효 & 조건 일치 52.2%”를 인간이 보증한 좋은 도형의 성공률로 해석하면 안 된다.
새 calibration에서 IoU≥0.80 및 전경 점유율≤0.35를 선택했다. 독립 test에서 깨끗한 도형 256/256, 약한 흐림 252/256을 유지했고 원·사각형·잡음 각각 64개는 전부 거절했다. 이것도 합성 대조군에 맞춘 자동 선별 기준이며 사람 검증을 대체하지 않는다.
기존 B2에서 새 기준과 모양·색 일치를 함께 만족한 비율은 seen 16.6%, OOD 12.5%였다. B1은 각각 3.8%, 1.7%였다. 모양·색 분류 결과 57.0%/34.0% 자체가 바뀐 것은 아니다.

일반 flow의 latent에도 이미 네 회전의 학습 표본이 들어 있다. 추가 회전 증강의 결과를 “회전 데이터를 못 본 모델과 본 모델의 차이”로 해석하지 않는다.

6,000-step C4 AE의 모양 정보는 선형 probe 45.4%, 비선형 RBF probe 75.0%로 읽혔다. 모양 정보의 부재로 단정할 수 없으며, 독립적으로 편집 가능한 개념으로 분리됐다는 뜻도 아니다.

## 완료한 새 데이터 확인 실험

기존 seed 42를 확인 표본에 포함하지 않고 완전히 새로운 데이터 seed 43001/43002/43003을 만들었다. 원본·기존 후속 평가 장면 및 새 split 사이의 회전 궤도 중복을 제거했다. 초기화 0/1/2와 조합해 AE 9개, 고정-step 일반/C4 flow 및 시간 통제 일반 flow 총 27개를 순차 실행했다. 조건은 실행 전에 `configs/confirmation_v1.json`에 고정했다.
프로세스 정상 종료, 최종 집계 `confirmation_v1/summary.json`, 추가 검증 `confirmation_v1/verification.json`의 통과를 확인했다. AE 9개와 flow 27개의 해시·고정 AE·초기 가중치·latent·평가 noise 짝맞춤, 새 장면 회전 궤도 5,376개, 원자료와 지표 집계를 검사했다. 사전에 정한 AE validation gate 미통과는 없었다.

주요 지표의 C4 우위는 고정 step/시간, 본 조합/제외 조합의 9개 짝 비교에서 모두 유지됐다. 각 모델 쌍의 고정 조건 안에서 생성 noise를 재표집한 조건부 구간과 데이터 seed별 효과를 따로 기록했다. 독립 데이터 seed는 3개이므로 모집단의 통계적 유의성을 주장하지 않는다.

## decoder 원인 분석 완료

동일한 학습 표현/정답 상태 × pixel/logit mean decoder × 3 초기화, 총 12개 학습을 마쳤다. 학습 표현을 복원할 때 logit mean은 mask IoU 0.843→0.893, 엄격 기준·모양·색 동시 통과 73.7→83.5%로 개선됐다. 같은 생성 latent를 두 새 decoder로 그리면 엄격 기준 통과는 17.4→21.5%였지만 모양·색 일치는 개선되지 않았다. 원래 decoder의 해당 생성 표본 결과는 16.2%였다.
복원 집계 216개, 회전 일관성, frozen AE·학습 자료·가중치 짝맞춤과 생성 표본 5,184행을 검증했다. 이 decoder 결과는 기존 진단 pool과 noise를 재사용한 개발 실험이다. 새 데이터의 확인 성능으로 부르지 않는다. 원인 분석과 다음 단계 모델 선택은 `STAGE_A_CONCLUSIONS_KO.md`에 있다.

## RGB 물체 모델과 외부 자료

정답 마스크를 훈련에 넣지 않는 flat/Slot Attention 소형 모델을 구현하고 순서 일관성·gradient·분리 지표를 검사했다. 첫 1,000-step pilot의 두 모델은 검은 배경으로 붕괴했다. 실패 결과와 코드를 보존했다. 두 번째 pilot은 선형 RGB 출력과 입력에서 계산한 전경/배경 균형 손실을 사용해 각 3,000 steps를 완료했다. 복원 전경 IoU는 flat 0.392, Slot Attention 0.455로 개선됐으나 물체-slot 대응 mask IoU는 0.093/0.072로 낮다. 전경 ARI만 높은 것을 물체 발견 성공으로 해석하지 않는다.

두 버전의 4개 모델을 CPU에서 다시 실행하고 저장된 mask와 지표 집계를 검증했다. validation만 본 개발 학습이며 B04의 전체 확인 실험을 완료한 것은 아니다. `object_perception_pilot_v2/RESULTS_KO.md`에 실패 원인 후보와 더 긴 학습·mask 진단 계획을 남겼다. 현재 이 두 pilot의 프로세스는 모두 정상 종료했다.

SVIB 공식 코드와 공개 preview 500개를 확보·검사했다. 외부 모델 평가와 전체 공식 프로토콜 실행은 남아 있다. Slot Attention, ISA, SysBinder, Dreamweaver, SEN의 본문·공식 코드 비교를 시작했고 `NEAREST_METHODS_REVIEW_KO.md`에 확인 범위와 미확인 독창성 범위를 기록했다.

- `initial_verification.json`의 검사는 원자료 해시·표본 수·집계·noise 짝맞춤에 대한 중간 일관성 검사다. 전체 연구 목표나 과학적 가설을 증명하는 완료 인증이 아니다.

## 운동·환경 데이터와 예측 pilot

C01/C02를 완료했다. 원형 물체의 기본 궤적 2,240개, 반대 행동 대응 궤적 512개를 생성했다. 상태 111,040개와 관측 영상 8,960장을 모두 재생했고, 외력까지 함께 회전하는 912개 궤적 및 외력 고정시 96개 반례를 검사했다. `dynamics_world_v1/RESULTS_KO.md`와 `verification.json`에 범위와 수치가 있다. 연속 물리나 학습 모델의 성능을 검증한 것으로 세지 않는다.

C03의 3개 환경×7개 모델을 1,000 steps 학습했다. 이후 표본 추출만 바꾼 대조 9회를 더해, 실제 30회 CPU 학습을 완료하고 예측 122,880개를 재생했다. 모든 모델이 전체 평균 속도 오차에서는 등속도보다 나빴다. 접촉을 강조한 학습에서 균일 표본으로 바꾸면 9개 모두 전체 평균은 좋아지고 접촉 순간은 나빠졌다. `dynamics_pilot_v1/RESULTS_KO.md`에 후속 학습 곡선·물리 기준선·독립 평가를 더 잘게 나눴다. C03은 진행 중이다.

RGB 물체 분리의 대조군으로 정답 마스크를 입력하지 않는 연결 영역 검출을 validation 128장에 적용했다. 영역 겹침 0.9973, 물체 수 128/128을 얻었지만 맞닿은 물체는 합치는 실패를 확인했다. 이는 쉬운 데이터의 기준선이며 학습된 표현이나 가림 복원을 입증하지 않는다. `object_component_diagnostic_v1/RESULTS_KO.md`에 비교와 검증을 기록했다.

## 물체 인식 추가 학습 종료

두 모델의 저장된 3,000-step 상태에서 각각 6,000/12,000 steps로 이어 학습했다. 추가 18,000 steps와 네 체크포인트 평가가 정상 종료했고, 부모 optimizer·원래 난수 흐름·CPU 예측 512개를 재검증했다. ## 이미지 모델 고정 평가 완료와 다음 상태 본 실험

B04의 평가 범위를 마쳤다. 12k 모델을 고정해 입력 attention·출력 mask·RGB 기여도를 나눴고, 공통 RGB 전경 후처리를 모든 보류 조건에 평가했다. 학습 모델 출력 1,536개, 물체 대응 6,912개, 복원 1,280행을 재검증했다. Slot+전경은 test IoU 0.628, 네 물체 0.742, 가림 0.427이었다. 개입 능력을 달성했다고 세지 않는다. `object_layers_heldout_v1/RESULTS_KO.md`에 범위·오류·검증·그림이 있다. B07의 물체 수/가림/합침/조각남 분석과 D02의 첫 그림을 진행했으며 개입 합성과 전체 동역학 그림은 남아 있다.
