# OrbitLab 연구 메모: 올바른 대칭의 이득은 어디까지 이어지는가

2026-09-23 · 합성 도형·물체 편집·동역학의 통제 실험. 현재 결과를 논의하기 위한 메모이며 새로운 고성능 모델이나 논문 독창성의 확정 주장이 아니다.

**질문.** 입력의 회전과 출력의 회전이 일치하도록 만드는 제약은 의미 있는 생성·개입·미래 예측을 얼마나 돕는가? 좋은 대칭성 수치와 실제 과제 성공을 구분하고, 실패가 관측 정보 부족, 인식, 상태 전이 중 어디에서 생기는지 비교했다.

**방법.** 원래 15회차 자료를 보존한 별도 작업 공간에서 평가기 음성 대조·기준 보정, 같은 표현 위의 flow 비교, 같은 횟수·시간의 학습 비교, 독립 데이터 반복, decoder 비교를 수행했다. 물체 편집은 정답 상태와 RGB 입력을 분리했고, 운동 예측은 정답 정보 교체, 환경 정보 누락 재학습, 관측 1·2·4·8장, 미래 1~61단계, 반대 행동을 비교했다. 모든 실험을 통합한 단일 모델은 아니다.

| 질문 | 관찰한 결과 | 해석의 경계 |
| --- | --- | --- |
| 대칭이 생성 품질을 높이는가 | 독립 데이터 3개×초기화 3개의 엄격 자동 성공률: C4 15.6%, 같은 시간의 일반 모델 5.3%. C4의 새로운 조합은 11.4%. | 이득은 있지만 절대 성공률은 낮다. 실제 사람 평가는 미수집이다. |
| 물체를 읽고 정확히 바꿀 수 있는가 | 새 장면 640개·편집 2,961개에서 RGB pipeline의 엄격한 전체 장면 성공은 관측 0건. 같은 개입 모델에 정답 상태·대상을 주면 새 다섯 조건 모두 100%. | 현재 고정 구성의 인식 오류가 크다. 무한 모집단의 성공 확률이 정확히 0이라는 뜻은 아니다. |
| 대칭의 이득이 미래 예측에 남는가 | 올바른 상태·외력 공동 회전이 일반 상호작용 모델보다 한 단계 속도 오차를 세 데이터 모두 줄였지만, 알려진 물리 참조보다 나빴고 긴 미래는 발산했다. | 한 단계의 이득을 안정적인 세계 모델의 증거로 옮길 수 없다. |

**새로 확인한 경계.** 같은 마지막 시점에서 측정+MLP 입력의 속도 추정 오차는 영상 1·2·4·8장에 각각 0.7405·0.0471·0.0574·0.0611픽셀/프레임이었다. 움직임을 볼 정보가 추가되는 이득은 크지만 관측 길이를 늘린다고 계속 좋아지지는 않았다. 여덟 장도 긴 미래의 불안정성을 해결하지 못했다. 이 측정기는 원형 모양·색·물리식의 사전 지식을 활용한다. 같은 영상과 행동이지만 숨은 환경 때문에 미래가 다른 구성 사례도 검증했으며, 이 사례의 하한을 전체 test의 오차 하한으로 확대하지 않는다.

**외부 확인과 반증.** 공식 SVIB 공개 예제 500쌍을 분할해 작은 모델 24개를 처음부터 학습했다. C4는 일반 모델보다 낫지만 네 학습 alpha 평균 모두 원본 복사보다 전체 픽셀 오차가 컸다. 공유 외부 test는 100장이고 일부는 실제로 변하지 않는 장면이므로 변경 영역·미변경 영역도 따로 평가했다. 전체 공식 SVIB나 기존 OrbitLab checkpoint 전이를 재현한 결과는 아니다.

**연구로서의 위치.** Slot Attention, ISA, SysBinder, Dreamweaver, SEN, Aether, PEnGUiN, PE-RL, Sparse World Models와 겹치는 문제를 확인했다. ‘대칭+숨은 외력’ 자체의 최초 제안이나 새 고성능 구조라는 주장은 적절하지 않다. 현재 기여 후보는 정보 제공 수준·대칭의 타당성·인식 단계·예측 시간을 함께 통제하고, 성공 지표와 실패를 재현 가능하게 연결한 진단이다. KAIST MLML에서 관심을 가질지, 논문으로 충분한지는 별도 연구 판단이 필요하다.

**다음 연구 제안.** 현재 계획의 실험과 구분해, (1) known-physics 참조에 충돌 잔차만 학습하는 모델로 장기 안정성을 검증하고, (2) 원본 복사를 넘는 변경 영역 예측을 고정 외부 split에서 확인하고, (3) Aether 또는 부분 대칭 방법 한 가지를 동일 입력 정보·예산으로 직접 비교하는 방향을 제안한다. 성능 목표와 예산을 먼저 정해 확인 실험을 설계해야 하며 이 세 추가 실험은 아직 실행하지 않았다.

**검증과 남은 한계.** 원본 1,324개 파일은 최초 해시와 일치한다. 예측 재생·집계·표·그림 검사를 각각 수행했다. 반복 데이터는 세 묶음에 불과하고, 일부 물체 인식 실험은 encoder 초기화 하나다. 실제 영상, 자연어 지시, 전반적인 인과 추론 능력은 검증하지 않았다. 출처를 가린 240장 사람 판정이 남아 있으며 이를 자동 판정으로 대신하지 않는다.
