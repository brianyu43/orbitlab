# B06 실행안: 공식 SVIB preview의 Shape-Swap 연결 실험

2026-09-23. 공식 dSprites / Single Atomic 공개 예제 500쌍을 사용한다. 이는 12개 과제 전체나 각 64,000개 학습·8,000개 평가의 공식 벤치마크 성능 재현이 아니다. 후속 계획 B06의 축소 외부 과제 연결에 해당하며, 전체 공식 벤치마크 실행 여부를 별도로 명시한다.

## 자료와 분할

공식 코드와 예제의 기존 고정 commit 및 2,000개 원본 파일 해시를 다시 검사한다. 128×128 PNG의 저장 채널을 그대로 PIL RGB로 읽고, 색 채널을 메타데이터에 맞춰 임의 변경하지 않는다. 학습 입력은 source 이미지뿐이고 target 이미지·장면 속성·변경 영역은 입력하지 않는다.

alpha=0.0/0.2/0.4/0.6의 각 100쌍을 공식 데이터 로더의 정렬·70%/15%/15% 방식에 따라 train 70, validation 15, ID test 15로 나눈다. 별도 Test 100쌍은 모든 alpha의 공통 미관측 조합 평가다. 학습·보류 source/target의 정확한 이미지 및 90도 회전 중복을 검사하고, source 조합과 target 조합의 노출을 따로 기록한다. 서로 다른 alpha와 초기화에서 재사용한 동일 test를 독립 데이터로 세지 않는다.

## 모델과 고정 학습 예산

1. 아무것도 바꾸지 않는 identity와 해당 train target만 평균한 상수 이미지 대조를 포함한다.
2. 작은 전역 병목 CNN encoder/decoder에 source 잔차 연결을 둔 영상 예측기를 처음부터 학습한다. 알려진 변환 규칙이나 정답 물체 속성은 입력하지 않는다.
3. 동일한 기본 예측기를 네 방향에서 적용하고 역회전 후 평균하는 C4 모델을 비교한다. 파라미터 수·초기 가중치·미니배치 순서를 맞춘다. 같은 2,000 steps, batch 8, Adam 0.0005, gradient clip 1, seed 0/1/2로 고정한다. 방식 2 × alpha 4 × 초기화 3 = 24개 학습이다.
4. 모든 모델의 마지막 checkpoint를 평가한다. validation·공통 test를 보고 seed·학습 횟수·checkpoint를 고르지 않는다. 학습 손실은 전체 픽셀 MSE다.
5. C4 모델은 같은 파라미터를 네 번 사용하므로 동일 계산 비용 비교가 아니다. 실제 학습 시간과 추론 비용을 기록한다. 기존 OrbitLab checkpoint를 전이한 결과나 새로운 데이터 독립 반복으로 부르지 않는다.

## 점수와 실패를 읽는 방법

- 공식 평가 코드의 `mse`는 픽셀·채널을 합한 오차를 이미지 수로 나눈 값이다. 원소별 MSE와 이 이미지별 제곱 오차 합을 모두 기록하고 128×128×3 배 관계를 검사한다.
- 전체 이미지, source/target 전경 합집합, 실제 변경 픽셀, 변경하지 않아야 할 픽셀의 오차를 구분한다. 전경과 변경 영역은 target을 사용하는 채점 전용 마스크다.
- 실제 변경이 없는 장면에서는 변경 영역 점수를 결측으로 두며 분모를 기록한다. 전체·변경 있음·변경 없음 집단을 모두 보고한다. identity가 맞는 장면 비율을 Shape-Swap 이해 정확도로 부르지 않는다.
- 모델과 identity의 오차 차이는 같은 장면끼리 계산한다. 모든 100개 외부 test 예제를 사용하고 마지막 미니배치를 버리지 않는다. 공식 평가 코드의 batch/drop_last/max_images 기본 실행과 다를 수 있음을 명시한다.
- 회전 입력에 대한 출력 일관성은 별도 지표이며 외부 과제 정확도를 대신하지 않는다. LPIPS를 실행하지 않았다면 미측정으로 표시하며 공식 전체 점수를 재현했다고 하지 않는다.
- 표는 alpha별 고정 초기화 세 개를 모두 보존한다. bootstrap을 사용하면 장면 단위 조건부 구간임을 밝힌다. 동일 공개 preview만 사용하므로 독립 데이터 seed 세 개의 확인 실험으로 해석하지 않는다.

## 완료 증거

원본 보존·입력/정답 분리·분할 및 노출 검사, identity/상수 대조, 24개 학습과 모든 보류 예측의 재생, 픽셀 지표 독립 재계산, 같은 장면 차이와 고정 예제 그림, 공식 프로토콜과의 차이표를 남긴다. 보고서에는 작은 공개 예제의 과적합·불확실성과 공식 전체 벤치마크 미실행을 명시한다. 실패한 결과도 같은 규칙으로 보고한다.
