# B05: 이미지 표현에서 실제 개입까지 연결하는 실행 세부안

2026-09-23. B04 고정 평가 이후의 실행안이다. 상태 판독기 6회 학습과 수정 평가, 새 장면 640개·과제 2,961개의 전체 RGB 개입 연결·재생 검증을 완료했다. [최종 고정 평가](reports/object_image_edit_v1/RESULTS_KO.md)와 [판독 평가 수정](reports/object_readout_pose_corrected_v1/RESULTS_KO.md)을 참고한다. 아래는 실제 실행에 사용한 단계와 경계다. B05의 평가 완료는 성공적인 편집 능력 확보를 뜻하지 않는다.

## 질문과 비교의 경계

RGB를 보고 얻은 표현에 모양·색·위치·크기·방향을 알아낼 정보가 있는지, 그 정보를 이용해 요청한 대상만 바꿀 수 있는지 조사한다. 단순히 마스크에 영상 변환을 적용하면 알려지지 않은 회전 중심이나 가려진 영역을 정답에서 가져오기 쉽다. 따라서 먼저 표현에서 상태를 읽는 단계와 명령을 수행하는 단계를 분리한다.

기존 flat/Slot Attention encoder·decoder는 고정한다. 물체 상태를 읽는 head의 학습에는 train의 정답 속성을 감독 신호로 사용한다. **정답 없이 개념을 발견한 실험으로 부르지 않는다.** 이미지 입력에 정답 상태나 마스크를 넣지는 않는다. 개입 controller는 B03의 학습 모델과 명시적인 정답 규칙을 구분해 연결하고, 전자는 이미 아는 상태에서 배운 규칙이 지각 오류를 얼마나 견디는지 측정한다.

## 작은 실행 단위

1. **RGB 표현 캐시:** 각 split에서 RGB만 읽어 고정 encoder의 5×32 slot을 저장한다. train과 평가 난수 흐름을 고정하고 checkpoint·RGB·latent 해시를 기록한다. 정답 속성 파일은 별도 loader로만 접근한다.
2. **상태 판독 head:** 공유 MLP로 각 slot의 16개 상태 성분을 예측한다. 훈련의 두 실제 물체와 예측 다섯 자리 사이 최소 비용 할당으로 감독한다. 범주/좌표/크기/방향/존재의 손실을 분리하고, GT 물체 순서를 바꿔도 손실이 같은지 검사한다. 빈 자리와 중복 검출을 함께 채점한다.
3. **독립 지각 평가:** 모델에 정답 개수나 대응을 제공하지 않는다. 평가는 예측과 정답을 대응시켜 누락/중복/모양/색/좌표/방향을 측정한다. 세·네 물체와 가림도 같은 용량으로 평가하며, 보이는 영역 분리와 가려진 속성 추론을 구분한다.
4. **대상 지정:** 이미지 모델에 보이지 않는 persistent object ID를 입력으로 주지 않는다. 실제 사용자가 제공할 수 있는 점 표시로 대상을 지정한다. 선택 위치의 생성 규칙과 추가 정보량을 고정하고, 대상 선택 오류와 변환 오류를 따로 측정한다. 중심·회전축을 정답에서 몰래 넘기지 않는다.
5. **개입 연결:** 예측 상태를 고정한 B03의 shared-object controller와 analytic rule에 각각 입력한다. 색·90도 회전·이동·색 이후 회전 합성을 모두 평가한다. 합성은 중간 정답을 넣지 않는다. identity 기준선도 포함한다.
6. **대응 유지와 성공 기준:** 최초 상태 평가에서 정한 대응을 개입 후에도 유지해, 다른 물체로 바뀐 예측을 재대응해 성공으로 세지 않는다. 목표 변경, 목표의 나머지 속성, 비대상 상태, 존재/개수, 전체 장면 성공과 연속 오차를 모두 보고한다.
7. **오류 전달 분석:** 정답 상태→controller, 예측 상태→analytic rule, 예측 상태→controller를 나눠 지각·선택·규칙 실행의 병목을 비교한다. 같은 장면의 여러 명령은 장면 단위로 묶어 불확실성을 계산한다.

## 확인 실험 운영

head 개발은 train/validation으로 제한한다. 이미 B04 분석에서 본 test를 새로운 학습 방법의 완전한 독립 확인 자료라고 부르지 않는다. 최종 head 설정을 잠근 뒤 기존 결과와 분리해 새 데이터 seed의 확인 자료를 만들고 원래 회전 궤도들과 중복을 검사한다. 원래 6,356개 개입 task의 결과는 별도 고정 모델 전달 진단으로 보고할 수 있다.

한 단계가 실패해도 결과를 남기며 이후 비교의 요구를 낮추지 않는다. 상태 판독이 잘되지 않으면 그 사실을 지각 병목으로 보고하고, 외부 SVIB와 동역학의 독립 작업은 계속한다. B05의 완료는 이미지 입력에서 실제 개입 출력·대상 선택·비대상 보존·물체 수/조합 평가까지 연결하고 재생 검증했을 때 판단한다.
