# C07.5 실행 단위: 현재 상태는 알고 환경 정보만 모를 때

2026-09-23. 아래는 후속 대조의 사전 실행안이다. 이 문서 작성 시점에 해당 재학습은 아직 실행하지 않았다. 기존 독립 반복, C07.4 관측 길이 비교, SVIB와 최종 연구 산출물의 범위를 줄이지 않는다.

## 질문과 입력

현재 물체의 정답 위치·속도·반지름·색·존재와 행동을 제공하고, 환경의 합력 또는 저항을 가리면 무엇을 예측할 수 있는가? 영상 인식 오류를 제거한 채 환경 정보 부족을 검사한다. 숨긴 값을 추론 중에만 0으로 바꾸는 대조와 달리 학습할 때부터 동일하게 가린다.

환경 입력 3차원과 전체 모델 용량을 유지한다. 합력 숨김은 앞의 두 좌표, 저항 숨김은 마지막 좌표, 모두 숨김은 세 좌표를 0으로 둔다. 마스크 종류는 실행 설정으로 고정하며 환경 이름이나 숨긴 참값을 추가 입력하지 않는다. 값 0은 해당 좌표를 모델이 관측하지 못하도록 하는 표준화된 입력이다. 이 설정을 저항이나 실제 힘이 0인 물리 세계로 바꾸었다고 해석하지 않는다.

## 고정 비교

- 독립 데이터: 기존 640031 및 신규 997101·997102. 같은 묶음 내부의 train/val/test/OOD 분할 유지.
- 학습 환경: variable_force train만 사용. 평가 환경마다 다른 가중치를 고르지 않는다.
- 모델: 일반 상호작용, 상태만 회전, 상태·외력 공동 회전의 세 가지. 이 세 가지는 대칭과 외력 정보의 관계를 비교하기 위해 같은 상호작용 구조를 사용한다. C07 독립 반복의 원래 일곱 모델 비교는 별도로 그대로 유지한다.
- 정보 조건: 전체 정보 및 합력 숨김·저항 숨김·둘 모두 숨김.
- 초기화: 기존 0/1/2와 같은 가중치 초기화·표본 추출·물체 순서 변경. hidden 48, 12,000 steps, batch 64, Adam 0.001, gradient clip 1.
- 신규 학습: 데이터 3 × 모델 3 × 초기화 3 × 누락 조건 3 = 81개. 전체 정보 대조 27개는 이미 학습·검증한 variable_force checkpoint를 재사용하고 해시로 묶는다.
- 평가: 모든 13개 보류 그룹의 전체 전이에 정답 현재 상태를 제공한다. 비교의 1차 지표는 장면별 한 단계 속도 MAE, 보조 지표는 위치 MAE와 접촉/비접촉/물체끼리/벽 접촉 층별 오차다. 동일한 variable_force 모델로 다른 환경도 평가하므로 환경별 별도 학습을 사용한 C03 표와 직접 섞지 않는다.
- 정보가 충분한 대조와 불충분한 대조의 학습 손실, validation, 고정 학습 종료 checkpoint를 모두 보존한다. 성능이 좋은 seed나 시점으로 바꾸지 않는다.

## 확인할 구조적 성질

관측 합력이 0으로 가려져 있을 때, 같은 내부 가중치를 가진 상태만 회전 모델과 공동 회전 모델은 현재 구현에서 같은 수학적 함수를 계산한다. 회전시킬 환경 벡터가 0이기 때문이다. 계산·gradient·짝맞춘 학습 결과의 일치를 확인할 수 있다. 이 일치는 숨겨진 실제 외력이 사라졌다거나 데이터의 조건부 분포가 반드시 회전 대칭이라는 뜻은 아니다.

## 답이 하나로 정해지지 않는 경우

충돌과 벽이 없는 동일 현재 상태·행동을 만들고, 숨긴 합력 또는 저항만 다른 두 환경에서 다음 상태를 계산한다. 모델이 받는 입력은 같지만 다음 정답이 다르면, 그 입력만 쓰는 결정적 예측기는 두 정답을 모두 정확히 맞출 수 없다. 두 사례를 같은 비중으로 둔 제곱 손실의 최솟값은 두 정답 차이의 제곱에 비례하며, 같은 정규화·물체 마스크로 직접 검사한다.

이 구성 예제의 오차 하한을 무작위 평가 자료 전체의 Bayes 오차로 확대하지 않는다. 기존 영상의 동일 과거·다른 미래 예제와, 현재 상태만 제공하는 이 예제를 구분한다. 정보가 충분한 모델도 틀릴 수 있으며 그 실패를 정보 부족으로 설명하지 않는다.

## 완료 기준

1. 설정·원본 자료·재사용 checkpoint·실행 코드의 해시를 학습 전에 고정한다.
2. 신규 81개 학습 및 108개 조건별 고정 checkpoint 평가를 완료한다.
3. 학습 표본·초기화·optimizer step과 모든 보류 예측·행별 점수를 재생한다.
4. 데이터 seed를 독립 단위로, 초기화를 짝맞춘 반복으로 집계한다. 숨김 효과가 없거나 반대로 나타나는 결과도 보존한다.
5. 구성 예제와 실제 무작위 자료의 결론을 분리해 보고한다. C07.4 관측 길이와 전체 후속 목표 완료 여부를 별도로 기록한다.
