# C07.4 실행 단위: 같은 순간을 보고 과거의 길이만 바꾸기

2026-09-23. 후속 사전 설계이며 이 문서 시점에 자료 생성·학습은 아직 실행하지 않았다. C07 독립 반복이나 환경 정보 누락 대조의 완료로 이 단계를 대신하지 않는다.

## 동일한 예측 과제를 유지하는 방법

기존 독립 데이터 640031·997101·997102의 초기 상태·환경·분할·행동 크기를 재사용하되, 행동 시점을 t=3에서 t=7로 옮긴다. 첫 8개 상태는 행동 전 관측이다. simulator에서 새로 전개해 train은 8개 관측+16개 미래, val/test/OOD는 8개 관측+61개 미래를 만든다. 원래 t=4 이후의 행동 적용 상태를 그대로 이어 붙이지 않는다.

각 장면의 마지막 상태 t=7, 행동, 미래 정답, train/val/test/OOD 분할은 모든 관측 길이에서 같다. 입력은 마지막 L개 영상으로 L=1/2/4/8이다. 평가 시점을 바꾸면 충돌과 위치 분포도 달라질 수 있으므로, L=4도 반드시 이 새 t=7 과제에서 처음부터 학습한다. 원래 t=3의 네 장 결과를 이 대조의 L=4 값으로 사용하지 않는다.

이 자료는 기존 자료의 초기 장면과 짝맞춘 별도 관측 연구다. 새로 전개한 궤적을 독립 데이터 seed 세 개가 더 생겼다고 세지 않는다. 동일 장면의 길이별 차이를 짝맞춰 분석한다.

## 정보량과 모델 용량을 구분하는 입력 계약

모든 L에 동일한 8개 시간 위치를 가진 입력 틀을 사용한다. 관측하지 않는 앞부분의 RGB와 측정값은 0으로 채우고, 각 시간 위치의 관측 가능 여부를 별도 표시한다. 가린 실제 영상·상태·측정값을 모델 전처리에 사용하지 않는다. L=1에서 숨긴 프레임으로 속도를 계산한 뒤 입력하는 방식은 금지한다.

이 설계에서는 L별 모델 구조·파라미터 수·초기 가중치를 정확하게 맞출 수 있다. CNN은 8×RGB와 8개의 관측 여부 채널을 받고, 측정 기반 MLP도 8개 시간 위치와 관측 여부를 같은 크기의 벡터로 받는다. 관측 길이에 따라 입력층 자체가 커지는 효과를 제거한다. 가림으로 인한 유효 입력 수 차이는 연구 대상이다. 원래 C04의 CNN 구조·입력과는 달라지므로 절대 점수의 변화를 관측 길이 효과로만 해석하지 않는다.

## 비교할 추정기와 예산

- 직접 RGB CNN과 알려진 원·색 측정을 사용하는 보정 MLP를 각각 학습한다. 알려진 renderer와 물리식을 사용하는 범위를 그대로 공개한다.
- 데이터 3 × 입력 길이 4 × 방식 2 × 초기화 3 = 신규 추정기 72개를 고정된 4,000 steps, batch 32, Adam 0.0005로 학습한다.
- 초기화와 train 표본 추출 순서를 L별로 정확히 맞춘다. 서로 다른 L의 결과로 학습 횟수·checkpoint를 고르지 않는다.
- 목표는 t=7 물체 상태와 환경의 합력·저항이다. train 정답만 감독 신호로 사용한다. RGB 모델에는 정답 물체 수·ID·마스크를 주지 않는다.
- 비학습 측정 참조는 L=1에서 위치·반지름·색 존재만 추정하고 속도·합력·저항은 사전 선언한 기본값으로 둔다. L=2에서 마지막 변위로 속도를 추정하되 합력·저항은 식별했다고 주장하지 않는다. L≥3의 추정식과 부족한 자유도·퇴화·접촉 처리 규칙은 결과를 보기 전에 별도 설정에 고정한다.
- 이미 검증한 variable_force 운동 예측기를 고정해 연결한다. 환경 이름에 따라 예측기를 바꾸지 않는다. 정답 t=7 상태·환경 대조를 함께 계산해 관측기의 오류와 운동 예측기의 오류를 구분한다.

## 평가와 완료 증거

1. 모든 L에서 마지막 상태·행동·미래 정답이 같은지, 숨긴 프레임을 바꿔도 모델 입력이 바뀌지 않는지 검사한다.
2. 데이터 궤적과 관측 RGB를 재생하고 학습·보류 회전 궤도 중복을 검사한다. 원래 자료와 의도된 초기 장면 대응은 별도 명시한다.
3. 상태·환경 추정, 한 단계 구성 요소 교체, 1/4/8/16/32/61단계 자율 예측, 동일 과거·반대 행동 반응을 기존 지표로 비교한다. 실패한 색 존재 판정과 수치 발산을 포함한다.
4. 물체 수·미학습 속성·미학습 외력·관측 중 접촉 여부별 결과를 보존한다. 관측 중 접촉 여부는 채점용이며 모델 입력이나 참조 추정기의 정답 필터로 사용하지 않는다.
5. 길이별 차이는 같은 장면·같은 학습 초기화끼리 짝맞추고, 독립 데이터 seed 세 개를 별도 단위로 집계한다. 더 긴 관측이 항상 더 좋다는 방향을 전제하지 않는다.
6. 모든 새 추정·연결 예측과 집계를 재생하고, 단일 영상의 속도 모호성 및 기존 동일 과거·다른 미래 구성 예제와 실제 오차를 구분해 보고한다.

구체적인 입력 전처리·손실 가중치·식별 추정식·학습 코드 해시를 고정한 설정 파일이 실제 실행의 기준이다. 이 설계 문서만으로 실행 완료를 주장하지 않는다.
