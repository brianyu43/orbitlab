# 관측 길이 비교의 최종 표시·해석 규칙

2026-09-23. 전체 12개 데이터·길이 조합의 예측은 생성됐고, 최종 재현 검증과 짝 집계는 아직 진행 중이다. 아래 표시 범위를 집계 결과를 읽기 전에 정한다. 이미 고정한 모든 지표·조건·예측 단계의 집계 범위를 줄이지 않는다.

1. 원본 집계 52개 관측 블록과 468개 자율 예측 블록을 모두 검증하고 인덱스로 제공한다. 본문 표·그림에는 정해진 진단 축을 표시한다.
2. 일반 variable_force/test를 중심으로 RGB CNN, 측정+MLP, 영상 측정+물리식의 위치·속도·합력·저항 추정과 동일 공동 회전 예측기의 한 단계 연결 오차를 비교한다. 물체 존재 실패를 0 오차로 지우지 않는 zero-filled 지표와 별도 성공 기준을 구분한다.
3. variable_force의 test/force_ood/count4를 모두 표시해 일반 조건만 고르지 않는다. 서로 다른 초기 장면 세 묶음의 평균·범위를 표시하고 각 데이터 평균도 표에 남긴다. 세 초기화가 독립 데이터 세 개를 추가하지 않는다.
4. 자율 예측은 공동 회전 모델과 알려진 force-wall 참조, oracle/측정+MLP/영상 물리식/RGB CNN 입력을 비교한다. 1/4/8/16/32/61단계의 위치 오차와 비유한 실패율을 함께 표시한다. 매우 큰 유한 오차도 제외하거나 상한으로 바꾸지 않는다. 위치 오차 그림은 로그축을 사용할 수 있고 원래 값은 표·연결 자료에 보존한다.
5. 주요 길이 차이는 같은 장면의 L8-L1, L8-L4로 표시한다. 비유한 예측이 있을 때 양쪽 점수가 유한한 공통 장면에서의 차이와 분모를 함께 보여준다. 각 길이 전체의 실패율을 별도로 남겨 생존 사례만으로 개선을 주장하지 않는다.
6. 접촉별 길이 비교는 고정한 L8 과거 7전이의 범주를 사용한다. 길이마다 보이는 접촉 범주가 달라지는 개별 평균을 직접 빼지 않는다. 전체 장면의 짝 차이가 주 비교다.
7. 반대 행동의 영향은 16·61단계에서 대상·비대상 위치 반응 오차와 무반응 대조를 나눠 표시한다. 서로 다른 물체로 전달된 효과의 실패를 대상 개선과 합치지 않는다.
8. t=7에 맞춰 다시 계산한 이 실험을 기존 t=3 결과의 단순한 성능 전후 비교로 부르지 않는다. 추가된 영상은 미래 입력이 아니며, 모든 길이는 동일 행동 이전 마지막 상태를 공유한다.
9. 결과 보고서 뒤 C07 종합에서 독립 반복·외력 누락·동일 입력/다른 미래 예시를 연결한다. 정보가 부족해서 구별할 수 없는 경우, RGB를 잘못 읽은 경우, 올바른 초기 상태에서도 예측이 무너지는 경우를 구분한다. 최적 오차의 일반 정리나 새로운 아키텍처의 우월성을 주장하지 않는다.

검증 완료 전에는 길이가 길수록 반드시 좋아진다는 결론을 적지 않는다. 최종 전체 연구 메모와 재현 묶음, 실제 사람 판정은 이 보고서 이후에도 별도 완료 증거가 필요하다.
