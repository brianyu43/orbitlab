# OrbitLab 후속 연구 실행

시작: 2026-09-23. 기존 15회차 자료는 기준 자료로 보존하고 이 디렉터리에 후속 코드·설정·결과를 추가한다.

목적은 현재 생성 차이의 원인을 밝히고, 물체별 조합과 개입, 환경 조건을 포함한 미래 예측까지 단계적으로 검증하는 것이다. 결과가 예상과 다르더라도 비교를 보존하고 다음 실험의 근거로 삼는다. 정확한 대칭의 구현 확인을 의미 이해·인과 발견의 증거로 대체하지 않는다.

상위 질문과 문헌은 [연구 제안서](../planning/MLML_RESEARCH_ROADMAP_KO.md), 세부 순서는 [작업표](PLAN_KO.md), 현재 실행 증거는 `reports/`와 `runs/`에서 관리한다. 원래 자료에 대한 해시 검사를 단계 시작과 최종 감사에서 수행한다.

사람 판정 자료는 출처를 가린 검토 도구와 응답 파일을 준비한다. 실제 사람이 제출한 판정이 없으면 사람 검증 완료로 표시하지 않는다. 이 경우 자동 평가에 관한 결과는 잠정 해석으로 유지하면서 독립적으로 수행할 수 있는 후속 작업을 진행한다.

## 최종 결과 안내

먼저 [쉬운 설명](reports/EASY_EXPLANATION_V2_KO.md)과 [연구 메모](reports/RESEARCH_MEMO_V2_KO.md)를 읽는다. [동역학 종합](reports/C07_SYNTHESIS_KO.md), [핵심 그림·영상](reports/FIGURE_CATALOG_KO.md), [항목별 최종 감사](reports/completion_audit_after_user_amendment_v1.md), [재현 절차](REPRODUCE_KO.md)가 연결되어 있다. 이전 진행 문서의 남은 일은 작성 당시 상태다.

사용자가 A04의 남은 판정을 AI에게 맡긴 변경을 반영해 **31/31항목을 완료**했다. 사람 9개와 AI 231개를 구분한 평가이며 전체 독립 사람 검증은 아니다. 원래 재현 ZIP의 70,514개 파일과 별도 폴더의 96개 모델·2,688개 표본 예측 검사를 통과했고, 새 판정은 아래 추가 ZIP으로 보존했다. [원래 재현 ZIP과 검사 기록](releases/orbitlab-followup-2026-09-23-v1/RELEASE_KO.md)의 29/31·30/31 상태는 이번 변경 전 기록이다.

## 사용자 요청에 따른 최종 갱신

사용자가 남은 판정을 AI에게 맡겨 A04를 사람 9개·AI 231개로 완료했다. [평가 방식 변경](PLAN_AMENDMENT_A04_KO.md)과 [현재 능력 보고서](reports/CURRENT_CAPABILITY_V2_KO.md)를 참고한다. **변경된 계획은 31/31 완료**이며, 240장 전체의 독립 사람 검증을 의미하지 않는다. [추가 판정 결과](reports/mixed_review_v1/aggregate_v1/RESULTS_KO.md)와 [약 1MB 추가 ZIP](releases/orbitlab-mixed-review-2026-09-23-v1/README_KO.md)을 보존했다. 기존 ZIP과 이전 보고서는 당시 상태를 보존한다.
