# C07: 독립 반복과 관측·환경 정보의 경계

2026-09-23. C05/C06 결과를 확인한 뒤의 후속 실행안이다. 동일 과거·다른 미래의 구성 예제만 이미 실행했다. 아래 독립 반복·관측 길이·조건 누락 학습은 아직 실행하지 않았다. 성공한 모델만 골라 확인 범위를 줄이지 않는다.

| 순서 | 실행 단위 | 완료 증거 |

| C07.1 | 독립 데이터 반복 설정 고정 | 현재 데이터와 겹치지 않는 새 생성 seed 2개, 기존 설정·학습 예산·입력 계약·모델 목록의 해시, 주요 비교와 실패 기준 |
| C07.2 | 새 데이터 및 기존 모델 프로토콜 반복 | 새 train/val/test/OOD/count 자료, 궤적 재생·회전/분할 중복 검사, 기존 세 환경×일곱 방식×세 초기화의 동일 예산 학습, 영상 추정기 반복 |
| C07.3 | 한 단계·긴 미래·행동 변경의 재확인 | C03–C06과 같은 채점, 데이터 seed별 결과와 초기화별 결과 분리, 수치 실패를 포함한 집계, 물체 수·속성 조합·외력·방향 효과별 결과 |
| C07.4 | 관측 길이 1/2/4/8 비교 | 행동 직전 시점을 동일하게 맞춘 별도 자료에서 과거 관측량만 변경, 마지막 상태·미래·행동·분할은 동일, 같은 예산 학습과 길이별 입력/모델 용량 차이 명시 |
| C07.5 | 환경 정보 누락 비교 | 정답 현재 상태를 주되 합력·저항·둘 모두를 가린 경우와 전체 정보를 준 경우를 비교. 학습과 평가에서 같은 정보만 제공하며, 원래 모델 입력을 사후에 0으로만 바꾼 것을 공정한 재학습 대조로 부르지 않음 |

| C07.7 | 재생·집계·연구 결론 | 모든 새 예측 재생, train 전용 전처리·자료 노출 검사, 데이터 seed 단위의 불확실성, 확인된 효과와 유지되지 않은 효과를 모두 보고 |

관측 길이 실험에서는 공통 행동 시점을 t=7로 옮기고 마지막 L개 프레임만 제공하는 설계를 사용한다. 따라서 L=4도 원래 C04의 t=3과 다른 분포이며, 같은 새 기준 시점의 L=4 대조를 함께 학습한다. 기존 자료에 미래 프레임을 추가해 과거라고 부르지 않는다. 모델의 합성곱 입력 채널 수, 알려진 원·색·물리 규칙 사용 여부와 단일 영상의 속도 추정 한계를 공개한다.

독립 반복은 성공률을 높이는 모델 탐색과 분리한다. C05/C06의 발산·긴 미래 오차·비대상 반응 실패가 새 데이터에서도 유지되는지를 먼저 확인한다. 관측 길이·조건 누락 실험의 세부 설정은 해당 자료와 결과를 보기 전에 별도 설정 파일에 고정한다. 관측 부족의 구성 반례를 무작위 자료 전체의 오차 하한으로 확대하지 않는다.

SVIB 외부 평가(B06), 가까운 선행 연구 비교(D01), 전체 핵심 그림(D02), 최종 연구 메모(D03), 재현 묶음(D04), 실제 사람 판정(A04)은 그대로 남아 있다.
