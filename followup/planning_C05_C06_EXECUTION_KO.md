# C05/C06: 정답을 다시 주지 않는 미래와 행동 변경

2026-09-23. C04를 완료한 뒤 작성한 실행안이다. 아래 평가 설정은 장기 예측 결과를 보기 전에 고정한다. 기존 학습과 결과를 변경하지 않는다.

1. **초기 정보 고정.** t=0..3 네 장으로 얻은 C04 추정 상태·환경을 한 번만 사용한다. 정답 상태+정답 환경, RGB 직접 CNN, 영상 측정+학습 보정, 영상 측정+물리식의 네 입력을 비교한다. 첫 방식만 명시적인 정답 대조군이다. 색으로 지정한 속도 변경 행동은 첫 예측에만 전달한다.
2. **비교 모델 유지.** 기존 variable_force의 일곱 학습 모델(flat/object/interaction/augmented/wrong_exact/joint_exact/relaxed), 세 초기화와 등속도·외력/벽 반사 비학습 참조를 모두 사용한다. 모든 환경에 같은 가중치를 쓰며 실제 환경 이름으로 예측기를 고르지 않는다. 용량·시간·사전 지식이 모두 같은 비교라고 주장하지 않는다.
3. **최대 61단계 자율 예측.** t=3에서 t=64까지 정답 상태·환경·개수·대응을 다시 공급하지 않는다. 학습 자료는 t=19에서 끝났으므로 16단계 이후는 학습 자료의 시간 범위를 넘는다. 1/4/8/16/32/61단계의 위치·속도 오차, 물체 누락과 잘못된 공간 대응, 벽 침범·물체 겹침을 기록한다. 출력 위치·속도를 임의로 제한하거나 물리 보정을 덧붙이지 않는다. 수치가 유한하지 않게 되면 최초 시점을 기록하고 이후를 실패로 유지한다. 유한한 사례의 오차와 전체 실패 비율을 함께 제시한다.
4. **충돌 시점 지표의 한계 명시.** 모델에는 충돌 출력이 없다. 프레임 사이 중심의 접근, 자유 운동에서 벗어난 속도 변화, 벽 근접으로 접촉 후보를 계산한다. 속도 잔차 0.1픽셀/프레임, 거리 여유 1.5픽셀을 사전에 고정한다. 원래 정답 상태에도 같은 판정을 적용해 이 지표 자체의 오차를 먼저 공개한다. 실제 simulator의 충돌 횟수와 같은 값이라고 부르지 않는다. 첫 접촉 시점 차이와 누락/허위 접촉, 프레임별 TP/FP/FN을 기록한다.
5. **같은 과거·반대 행동.** 이미 생성하고 검증한 512개 대응 궤적에서 초기 추정과 환경은 고정하고 행동 부호만 바꾼다. 두 예측의 차이를 두 정답 미래의 차이와 비교한다. 대상과 비대상 물체를 분리한다. 충돌을 통해 다른 물체가 움직이는 것이 정답이므로 비대상을 무조건 보존하도록 채점하지 않는다. 행동에 전혀 반응하지 않는 대조의 오차도 기록한다.
6. **독립 재생과 보고.** 초기 한 단계는 C04의 저장 예측과 맞춰 검사한다(겹치는 다섯 예측기). 모든 궤적을 저장 초기 입력에서 재생하고 주요 지표를 별도 코드로 재계산한다. 고정 가중치·데이터·소스 해시를 확인하고, 모델/조건별 세 초기화와 장면 단위 불확실성을 분리한다. 예측 프레임 수를 독립 표본 수로 세지 않는다.

원본 보류 궤적은 13개 그룹 1,280개, 반대 행동은 그중 512개다. 데이터 생성 seed는 하나이며 독립 데이터 반복·관측 길이·조건 누락 연구는 C07에 남는다. 외부 SVIB, 선행연구, 사람 판정 및 최종 재현 묶음도 전체 목표의 일부로 유지한다.
